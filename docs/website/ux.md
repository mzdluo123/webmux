# 交互与可访问性

官网的交互目标只有两个：让访客用最少的动作理解产品并复制安装命令；让任何输入方式（鼠标、触摸、键盘、屏幕阅读器）都能完成同样的任务。本页按 Nielsen 可用性启发式与 WCAG 2.2 AA 列出必须满足的规则。

## 导航模型

- 顶部导航不超过六项；当前页高亮；页头固定高度 56–64px，滚动时保持可见但不遮挡内容锚点（设置 `scroll-margin-top`）。
- 第一个可聚焦元素是“跳到主要内容”链接，Tab 时可见。
- 小于 640px 时导航折叠为菜单按钮：按钮有 `aria-expanded` 与可见标签；菜单打开时焦点进入菜单，Esc 关闭并把焦点还给按钮。
- 文档类页面提供面包屑与侧栏目录；长页面提供“本页目录”（`<nav aria-label="本页目录">`）。
- 页脚是完整的站点地图，保证任何页面两次点击内可到达其他页面。

## 首屏任务

- 首屏必须同时出现：定位句、安装命令、主图。访客不滚动也能完成“理解 + 复制”。
- 主 CTA 是一个带复制按钮的命令框，而不是跳到另一页的按钮；按钮紧邻命令（减少指向距离），尺寸不小于 44 × 44px。
- 按钮文字描述结果：“复制安装命令”“查看全部下载”。
- 次要入口（GitHub、演示）视觉权重明显低于主 CTA。

## 渐进披露

- 高级选项（镜像、固定版本、安装目录）默认折叠在“更多选项”里，用原生 `<details>`，展开状态不写入 URL。
- 对比表在小屏改为逐项卡片；完整截图画廊的“更多截图”默认折叠。
- 安全提示不折叠：它是边界说明，必须在首页与下载页可见。

## 反馈与状态

- 复制成功：按钮文字变为“已复制”约 2 秒，并通过 `aria-live="polite"` 区域播报；失败（如非安全上下文）时显示可手动选中的文本框。
- 外部链接带图标与 `rel="noopener"`；下载链接显示文件大小与 SHA-256 前八位，并链接到完整 `SHA256SUMS`。
- 构建期数据缺失时页面显示“版本信息暂不可用，请到 GitHub Releases 查看”而不是空白。
- 404 页：说明页面不存在、提供首页 / 下载 / 文档 / GitHub 链接与站内搜索，HTTP 状态为 404。

## 渐进增强

- 所有核心内容（命令、下载链接、FAQ、对比）在无 JavaScript 时完整可用：默认渲染 Linux / macOS 命令，脚本只负责按操作系统切换与复制。
- 操作系统识别使用 `navigator.userAgentData` 并回退到 `navigator.platform`，识别失败时保持默认标签页；识别结果只用于预选标签，不隐藏其他选项。
- 主题与语言切换不依赖脚本也能用：语言切换是普通链接，主题由 CSS 跟随系统，脚本只增加手动覆盖。

## 移动端

- 最小字号 16px，触控目标最小 44px，间距不小于 8px；页面不出现横向滚动。
- 命令与代码块可横向滚动并显示滚动提示（右侧渐隐或滚动条），长命令不截断。
- 表格在小屏改为堆叠卡片或可横向滚动的容器，并保留表头语义。
- 固定页头在手机上不超过 56px，底部不放固定浮层。
- 在 320px 宽度与 200% 文字缩放下检查所有页面不溢出。

## 键盘与焦点

- 所有交互元素可用 Tab 到达，顺序与视觉一致；焦点环使用主色，`:focus-visible` 可见且不被固定页头遮挡（WCAG 2.4.11）。
- 标签页（安装方式切换）实现 ARIA Tabs 模式：方向键切换、Tab 进入面板；可展开区域用原生 `<details>`。
- Esc 关闭菜单与弹层；页面没有键盘陷阱；不劫持浏览器快捷键。

## WCAG 2.2 AA 要点

- 文本对比度不低于 4.5:1，大文字与图形不低于 3:1（令牌对比值见 [视觉规范](design.md#颜色令牌)）。
- 每页一个 H1，标题层级不跳级；`<html lang>` 为 `zh-CN` 或 `en`，页内英文术语不必标注。
- 图片有描述性替代文本；装饰图标 `aria-hidden`；状态不只靠颜色表达，带文字或图标。
- 动效尊重 `prefers-reduced-motion`；没有闪烁内容；自动播放视频静音且可暂停。
- 目标尺寸不小于 24 × 24px（2.5.8），实际按 44px 执行；帮助入口（文档、FAQ、GitHub）在每页位置一致（3.2.6）。
- 表单（站内搜索）有可见标签；错误信息用文字说明。

## 启发式对照

| 启发式         | 官网的落实                                       |
| -------------- | ------------------------------------------------ |
| 系统状态可见   | 复制反馈、版本条、下载大小与校验值               |
| 贴近真实世界   | 文案用用户动作而非系统术语；安装步骤按真实顺序   |
| 用户控制与自由 | 操作系统识别可手动改；主题与语言可切换；无弹窗   |
| 一致与标准     | 与产品共用令牌、图标、圆角；按钮只有三种         |
| 防错           | 镜像与公网访问附风险说明；升级提示会结束会话     |
| 识别优于回忆   | 命令完整可复制，不要求记忆参数；FAQ 直接给答案   |
| 灵活与效率     | `/install.sh` 短链接；键盘可完成全部操作         |
| 极简美学       | 每区块一个任务一个 CTA；无装饰动画               |
| 帮助用户恢复   | 404 与数据缺失有明确下一步                       |
| 帮助与文档     | 页脚与导航固定的文档入口；每个功能链接到对应文档 |

## 性能预算

性能是交互的一部分，也是搜索排名因素。在移动端模拟（Lighthouse 默认节流）下：

- LCP ≤ 2.5s，INP ≤ 200ms，CLS ≤ 0.1；Lighthouse 性能、可访问性、最佳实践、SEO 四项均 ≥ 95。
- 首页首屏传输（HTML + CSS + 首屏图片 + 字体）≤ 200 KB，JavaScript 总量 ≤ 50 KB（压缩后）。
- 字体自托管且子集化；图片带尺寸并用现代格式；无第三方脚本阻塞渲染。
- 在 CI 中用 Lighthouse CI 固化上述预算，超限即失败。

## 测试清单

- 自动：axe（或 pa11y-ci）扫描全部页面；Lighthouse CI；链接与锚点检查；HTML 校验。
- 手动：仅用键盘走完“首页 → 复制命令 → 下载页 → FAQ”；iOS VoiceOver 与 Windows NVDA 各走一次首页；320px 宽与 200% 缩放；深浅色各一次；慢速 3G 下首页可读。
- 回归：每次改动导航、CTA 或命令框后重跑上述手动项。
