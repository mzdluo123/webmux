# 官网验收清单

按阶段逐项打勾。每一项都对应前面各页的规则；拿不准时回到对应页面查原文。清单分为建设阶段、上线日与上线后的维护。

## 阶段 0：准备

- [ ] 域名已注册并启用 HTTPS；`www` 与裸域的重定向方向已定（[域名](stack.md#域名)）。
- [ ] 官网仓库已创建，Node 版本与主仓库 `.nvmrc` 一致，pnpm 锁文件提交。
- [ ] 托管平台（推荐 Cloudflare Pages）已连接仓库，主分支自动部署，PR 有预览链接。
- [ ] 隐私友好统计已选定且无 Cookie；事件名称按 [转化漏斗](strategy.md#转化漏斗与度量) 定义。
- [ ] 价值主张、主标题与六个卖点文案已定稿，中英文各一版。

## 阶段 1：骨架与数据

- [ ] Astro 项目按 [项目骨架](stack.md#项目骨架) 建立；`astro check` 通过。
- [ ] `fetch-releases.mjs` 能读取最新 Release 并写入 `releases.json`；API 失败时回退副本生效且构建不中断。
- [ ] `sync-assets.mjs` 从指定 tag 复制 Logo、截图、字体与许可文件，并生成来源清单。
- [ ] 令牌文件从 `design-tokens.css` 派生，深浅色都能渲染。
- [ ] 基础布局（页头、页脚、跳转链接、主题与语言切换）完成，无脚本时可用。
- [ ] `_headers`、`_redirects`、`robots.txt`、站点地图、404 页已就位。
- [ ] `sync-docs.mjs` 从同一 tag 生成 `/docs/` 内容：排除列表生效、链接与锚点按 GitHub 规则改写、GitHub 提示块转为 aside、每页带“在 GitHub 上查看”与版本标注（[文档镜像](stack.md#文档镜像)）。
- [ ] 文档侧栏分组与主仓库 [文档中心](../README.md) 一致；Pagefind 搜索可用且支持中文。
- [ ] 链接与锚点检查：`make docs-check` 认可的相对链接在官网全部可解析，未映射者使构建失败。

## 阶段 2：页面与内容

- [ ] 首页十一个区块按 [首页区块](pages.md#首页区块) 实现，每区块一个主 CTA。
- [ ] 下载页资产分组、大小、SHA-256、升级提示、镜像说明齐全。
- [ ] FAQ、安全、对比、更新日志、Windows 页完成；对比页有核对日期。
- [ ] 所有数字能追溯到仓库文档或 Release；README 中过时的“约 15 MB”未被照搬。
- [ ] 安全边界在首页与下载页可见且未被折叠。
- [ ] 英文版经人工校对；专有名词两种语言一致。
- [ ] 页脚含 MIT 许可、字体与图标许可、商标声明。

## 阶段 3：视觉一致性

- [ ] 页面上的颜色、字号、圆角全部来自令牌表（[视觉规范](design.md#一致性自检)）。
- [ ] 浅色主题中没有把 `#85d9a5` 当文字或图标色。
- [ ] Logo 深浅两版按系统切换；favicon、OG 图、`apple-touch-icon` 使用同一图标。
- [ ] 所有截图来自 `docs/images/`，深浅色配对正确，带宽高属性，单张不超过 200 KB。
- [ ] 图标统一为 Tabler；agent 品牌图标为 LobeHub 单色版。
- [ ] 深浅色各截一次首页与下载页并排比较，无主题切换闪烁。

## 阶段 4：站点功能

- [ ] 安装命令生成器：操作系统预选、镜像开关、固定版本、复制反馈、无脚本回退（[功能 1](features.md#1-安装命令生成器)）。
- [ ] 下载表由构建期数据生成，未知资产进入“其他”。
- [ ] 更新日志每版本独立 URL，Atom 订阅可被阅读器解析。
- [ ] `/install.sh` 重定向到 GitHub Release 资产：`curl -fsSL https://<域名>/install.sh | sh -n` 通过。
- [ ] `llms.txt` 存在且与首页事实一致。
- [ ] 统计事件在复制、下载、GitHub 跳转时触发，且不含个人数据。

## 阶段 5：交互与可访问性

- [ ] 仅用键盘走完“首页 → 复制命令 → 下载页 → FAQ”；焦点环可见且不被页头遮挡。
- [ ] 菜单与标签页符合 ARIA 模式：`aria-expanded`、方向键、Esc 关闭并归还焦点。
- [ ] axe 或 pa11y 扫描全部页面零严重问题；每页一个 H1，`lang` 正确。
- [ ] 320px 宽与 200% 缩放无横向滚动；触控目标不小于 44px。
- [ ] iOS VoiceOver 与 NVDA 各走一次首页，命令框与复制按钮可被正确朗读。
- [ ] `prefers-reduced-motion` 下无非必要动画；视频静音可暂停。

## 阶段 6：性能与 SEO

- [ ] Lighthouse 移动端四项 ≥ 95；LCP ≤ 2.5s、INP ≤ 200ms、CLS ≤ 0.1；预算已写入 Lighthouse CI。
- [ ] 首屏传输 ≤ 200 KB，JavaScript ≤ 50 KB；字体自托管并子集化。
- [ ] 每页 `title`、`description`、`canonical`、OG / Twitter 标签齐全；OG 图 1200 × 630。
- [ ] `hreflang` 两两互指并含 `x-default`；站点地图包含全部语言版本。
- [ ] JSON-LD（`SoftwareApplication`、`FAQPage`、`BreadcrumbList`、`WebSite`）通过富媒体结果校验。
- [ ] 链接检查（含锚点）零失效；没有孤立页面；文档页 `canonical` 指向官网且各页 `title` / `description` 不重复。
- [ ] `robots.txt` 对 AI 爬虫的态度已明确。

## 上线日

- [ ] DNS 切换完成，HTTPS 证书有效，HSTS 生效。
- [ ] Google Search Console 与 Bing Webmaster 验证并提交站点地图；IndexNow 已开启。
- [ ] GitHub 仓库 Website 字段、README 首行、`deploy/linux/nfpm.yaml` 的 `homepage` 指向官网（主仓库另开 PR）。
- [ ] Release 说明模板加入官网更新日志链接。
- [ ] 社区发布稿准备好：一句话定位、主图、安装命令、官网链接。
- [ ] 上线后 24 小时内复查统计事件是否到达、404 日志是否异常。

## 维护：每次 Release

- [ ] 站点已自动重建（定时、手动或 `repository_dispatch`），首页版本号与下载表为新版本。
- [ ] 更新日志页出现新版本，Atom 订阅更新。
- [ ] 文档镜像已按新 tag 重新同步，清单差异经审查；新文档出现在侧栏，删除的文档做了 301。
- [ ] 产品行为有变化时，先改主仓库文档与截图，再运行同步脚本更新官网。
- [ ] 若安装命令、资产命名或平台支持有变化，更新安装命令生成器与下载表分组规则。

## 维护：每月与每季度

- [ ] 每月：查看 Search Console 查询词与点击率，改写“展示多、点击少”的标题；查看统计中的转化率。
- [ ] 每月：链接检查与 Lighthouse 重跑；处理“已发现但未编入索引”的页面。
- [ ] 每季度：复核证据点与对比表是否仍然成立，更新核对日期；复核关键词地图。
- [ ] 每季度：更新依赖版本（Astro、集成、字体子集），重新跑全部门禁。
