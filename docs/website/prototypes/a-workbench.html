让 agent 在服务器上一直跑，你在任何设备上随时接管。

WebMux 是一个在浏览器里持续运行的终端。会话放在服务端，电脑、手机和本机终端只是附着上去：合上笔记本，Claude Code、Codex 照样干活；它提问时，在手机上回一句就行。

curl -fsSL https://github.com/mzdluo123/webmux/releases/latest/download/install.sh | sh
Linux · macOS · Windows（WSL 2） 单二进制，约 20 MB MIT 许可 其他安装方式 →

三步看懂

这一路是同一个进程，一行输出都不会丢。

① 电脑上开工

同时跑多个 agent，总览里一眼看出谁在干活、谁在等你。

② 手机上接管

锁屏推送叫你回来；软键栏、触摸滚动，TUI 照样好用。

③ 回到电脑审阅

终端旁直接看 Diff，一键把 路径:行号 发给 agent。

为什么会爱上它

断线不断会话

锁屏、换网、关标签页都不影响；重连只补发缺失的输出。

原样运行你的 agent

Claude Code、Codex、Gemini 等九款 CLI 预置即用，跑在真实 PTY 里。

TUI ↔ 聊天一键切换

同一段对话，电脑上用 TUI，手机上用聊天视图，历史完整保留。

它在等你时会告诉你

识别 agent 的提问与授权请求：总览标记、标签页提示、锁屏推送。

写代码的工作台

分屏、草稿模式、代码与 Diff 浏览、Git worktree、终端里显示图片。

轻到可以忘了它

单二进制、空闲约 13 MB 内存，无需 root、tmux 或数据库；Windows 经 WSL 2 一等支持。

两分钟装好

脚本自动识别架构并校验 SHA-256，安装到用户目录，不需要 sudo，也不改写 shell 配置。

deb / rpm、手动下载与 Windows 安装程序 →
1. 安装 
curl -fsSL https://github.com/mzdluo123/webmux/releases/latest/download/install.sh | sh
2. 运行，然后打开 http://127.0.0.1:7681 
webmux --listen 127.0.0.1:7681
安全边界：WebMux 等同于以当前用户身份把 shell 暴露到网络。仅本机使用请监听 127.0.0.1；远程访问请绑定 Tailscale / WireGuard 等可信 VPN；不要直接开放到公网。阅读安全模型
