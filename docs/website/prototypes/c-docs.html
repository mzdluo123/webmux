使用指南

基于 v0.10.1 的文档 在 GitHub 上查看 编辑此页

会话列表

首页按仓库 / 工作树分组展示所有会话，实时显示标题、状态（运行中 / 可能在等你 / 空闲 / 已退出）和终端屏幕预览。同时跑多个 agent 时，总览里一眼看出谁在干活、谁在等你。

需要你介入的提醒

程序主动发出的终端信号优先于启发式：一旦收到，会话显示具体提醒并保持“等待”，即使 agent 仍在刷新 spinner、计时器或状态栏。

提醒 来源
需要回答 OSC 7501 状态 blocked（kind=question、auth 或未注明）
等待授权 OSC 7501 状态 blocked 且 kind=permission
本轮完成 OSC 7501 状态 done；Warp 结构化事件 stop / idle_prompt
响铃提醒 终端响铃（BEL），在你最后一次输入 1 秒后才计入
说明  OSC 7501 是 Program Status Protocol：程序直接报告自己处于空闲、工作中、阻塞、完成还是出错。webmux 只读取 state 与 kind，正文从不解析、保存或下发。

Claude Code（2.1.295 及以上）：无需配置。它在启动时发出 OSC 7501;? 探测，得到 webmux 的应答后报告状态。 

webmux run -- claude      # 在常用终端里启动，Ctrl+] 分离后去手机上继续
webmux attach <ID>        # 回到电脑后接续同一个进程
