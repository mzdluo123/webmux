下载与安装

最新版本 v0.10.1 2026-11-02 发布 SHA256SUMS 更新日志 GitHub Release

脚本自动识别 Linux / macOS 与 amd64 / arm64，下载对应二进制与 SHA256SUMS，校验通过后才原子替换目标文件。默认安装到 ~/.local/bin/webmux，不需要 sudo，不改写 shell 配置。

curl -fsSL https://github.com/mzdluo123/webmux/releases/latest/download/install.sh | sh
更多选项：国内镜像、固定版本、安装目录
镜像是第三方服务，能看到请求者 IP；二进制与 SHA256SUMS 必须来自同一来源并通过校验。 
curl -fsSL https://ghfast.top/https://github.com/mzdluo123/webmux/releases/latest/download/install.sh \
  | WEBMUX_VERSION=0.10.1 WEBMUX_INSTALL_DIR="$HOME/bin" sh
然后运行，在浏览器打开 http://127.0.0.1:7681，点击“新建会话”： 
webmux --listen 127.0.0.1:7681

下一步

  • 让服务常驻后台：webmux start，或 安装为用户服务。
  • 从手机访问：绑定 Tailscale / WireGuard 地址并启用 token，见 远程访问。
  • 在常用终端里启动 agent：webmux run -- claude，Ctrl+] 分离后去手机上继续。

升级提示：重复执行脚本即升级；正在运行的服务需手动重启，重启会结束所有终端会话，先让 agent 告一段落。

表中只列出常用资产；ARM64 Windows 客户端、Windows 安装程序与 deb / rpm 包见 GitHub Release。手动校验： 

sha256sum --check --ignore-missing SHA256SUMS   # macOS: shasum -a 256 -c --ignore-missing SHA256SUMS

安全边界。WebMux 等同于以当前用户身份把 shell 暴露到网络，默认监听 0.0.0.0:7681。仅本机使用请改为 127.0.0.1；远程访问请绑定可信 VPN；除非明确使用隧道并接受“Token 是唯一入口屏障”的风险，不要开放到公网。阅读安全模型
