desktop · 回到电脑审阅

写代码的工作台，不只是终端

终端旁直接看 Diff，一键把 路径:行号 发给 agent；分屏、草稿模式、Git worktree、终端里显示图片。

  • ▸断线不断会话：锁屏、换网、关标签页都不影响。
  • ▸原样运行你的 agent：跑在真实 PTY 里，无插件、无改写。
  • ▸它在等你时会告诉你：总览标记、标签页提示、锁屏推送。
  • ▸轻到可以忘了它：单二进制，无需 root，Windows 经 WSL 2 一等支持。
install · 两分钟装好

装到用户目录，不需要 sudo

脚本自动识别架构并校验 SHA-256，不改写 shell 配置。重复执行即升级。

deb / rpm、手动下载与 Windows 安装程序 → 
# 1. 安装
curl -fsSL https://github.com/mzdluo123/webmux/releases/latest/download/install.sh | sh

# 2. 运行，然后打开 http://127.0.0.1:7681
webmux --listen 127.0.0.1:7681
安全边界  WebMux 等同于以当前用户身份把 shell 暴露到网络。仅本机使用请监听 127.0.0.1；远程访问请绑定可信 VPN；不要直接开放到公网。阅读安全模型 →
