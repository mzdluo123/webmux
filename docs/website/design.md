# 视觉与品牌规范

官网与产品界面必须看起来出自同一只手。产品的 [设计系统](../design-system.md) 定下了“克制的开发工具”方向：中性色、绿色强调、明确的信息层级、工作内容优先。官网在此基础上只放宽排版尺度，不引入新的色彩或装饰语言。

## 选定方向：叙事长卷

2026-11-03 在四个候选方向（工作台、深色终端、叙事长卷、双屏对偶）中选定 **叙事长卷**。候选画板由维护者保存在设计画布中，本节是它的可执行规格，后面各节的令牌与规则都以它为准。它的特征：

- 浅色、大留白、左对齐大标题。
- 首页用三段左右交替的图文把“电脑开工 → 手机接管 → 回来审阅”讲成一个故事。
- 卖点用无卡片的定义列表，安装区用下划线式标签页。

### 版面

- 容器宽 1040px，侧边距桌面 24px、手机 16px；区块纵向间距桌面 96px、手机 64px；叙事行之间 96px。
- 页面底色 `#ffffff`；分段带使用 `#f7f9f8`，上下各 1px `#eef2f0` 分隔线；不使用卡片承载内容，只用留白与分隔线分组。
- 网格 12 栏、列距 40px：叙事行文字 5 栏、截图 7 栏，逐行左右交替；卖点区标题 4 栏、定义列表 8 栏两列。

### 页头与 Hero

- 页头 72px 高，无底边线：左侧横向标志 26px 高，主导航 15px（它怎么工作 · 安装 · 文档 · 常见问题），右侧 GitHub 文字链接、`EN`、绿色填充按钮“安装 WebMux”（40px 高、6px 圆角）。
- H1 60px / 行高 1.12 / 字重 700 / 字距 -0.02em，最大宽 880px，左对齐；副标题 20px / 行高 1.65、次要文字色，最大宽 640px。
- CTA 行：命令框（`#f7f9f8` 底、1px 边框、6px 圆角、右侧 48px 宽的图标复制按钮）+ 一行 14px 元信息（版本 · 平台 · 许可）。
- 主图 `hero.jpg` 全宽置于 Hero 文字之下，8px 圆角、1px 边框；首屏不放第二个按钮。

### 叙事行与卖点

- 每段叙事：等宽小标（如 `01 / 电脑上开工`，13px、主色）→ H2 34px / 1.25 / 700 → 正文 17px / 1.75 次要色；段落文案取自 README 的场景叙述。
- 第二段的两张手机截图并排，各占所在栏的 44%；其余段落单张桌面截图，8px 圆角、1px 边框、白底。
- 卖点使用 `<dl>`：`dt` 17px / 600，`dd` 15px / 1.7 次要色；不加图标、不加卡片边框。

### 安装区与提示

- 位于 `#f7f9f8` 分段带内；标签页为文字 + 2px 主色下划线（Linux / macOS · Windows（WSL）· deb / rpm · 手动下载），ARIA Tabs 模式。
- 步骤用有序列表，句首加粗（“1. 安装。”），每步一段 14px 等宽命令块（白底、1px 边框、6px 圆角）。
- 安全提示为独立段落：边框 `#f2c66d`、底 `#fff8e8`、文字 `#5a3d06`、8px 圆角，不用左侧色条；深色主题换用下文令牌。

### 链接、按钮与页脚

- 正文链接主色带下划线（`text-underline-offset: 3px`）；导航与页脚链接无下划线，悬停加下划线。
- 全站只有三种按钮：主色填充、描边、文字链接；首页主色填充按钮只出现在页头与安装区。
- 页脚单行：标志 22px、文档中心 · 更新日志 · 安全策略 · GitHub，右侧“MIT 许可 · 开源项目，与 agent 厂商无隶属关系”。

### 深色主题映射

跟随系统并可手动覆盖；深色下令牌逐项替换：

- 页面底 `#111814`，分段带 `#19211c`，分隔线与边框 `#34443b`。
- 正文 `#eef2f0`，次要文字 `#a5b4ab`，主色 `#85d9a5`（填充按钮文字用 `#111814`）。
- 命令块底 `#0d1117`、文字 `#c9d1d9`；安全提示边框 `#895b0a`、底 `#1b1810`、文字 `#f2c66d`。
- 截图优先使用深色对应版本，没有时用浅色截图加 1px `#34443b` 边框。

### 手机版（小于 640px）

- H1 36px / 1.15，副标题 17px；命令框整行显示，复制按钮 44px 高。
- 叙事行堆叠为“小标 → 标题 → 正文 → 截图”；两张手机截图仍并排各 48%。
- 卖点定义列表单列；安装标签页横向滚动，不换行；页头折叠为菜单按钮，“安装 WebMux”按钮保留在页头。

### 内页

下载、FAQ、对比、更新日志沿用同一容器、字号尺度与分段带；文档镜像使用 Starlight 布局但覆写其令牌：侧栏 260px，正文最大宽 760px，字体、颜色、圆角与首页一致。

## 原则

1. **截图是主角**。营销页最有说服力的素材是真实界面，版面围绕截图组织，背景保持中性。
2. **一个强调色**。绿色只用于主 CTA、链接与成功状态；不做渐变、光晕、大面积品牌色块或装饰动画。
3. **层级稳定**。标题 → 一句话收益 → 证据（截图或数字）→ 行动，每个区块都按这个顺序。
4. **深浅色同等重要**。所有截图、Logo、OG 图都有两套；默认跟随系统。

## 颜色令牌

令牌从 `web/src/design-tokens.css` 派生，保持同名，官网的 `tokens.css` 只增加营销页需要的大尺寸排版变量。

| 角色       | 浅色                     | 深色                     |
| ---------- | ------------------------ | ------------------------ |
| 页面背景   | `#f7f9f8`（neutral-50）  | `#111814`（neutral-950） |
| 卡片表面   | `#ffffff`（neutral-0）   | `#19211c`（neutral-900） |
| 正文       | `#19211c`（neutral-900） | `#eef2f0`（neutral-100） |
| 次要文字   | `#5f6d65`（neutral-500） | `#a5b4ab`                |
| 边框       | `#dce3df`（neutral-200） | `#34443b`（neutral-700） |
| 主色 / CTA | `#217346`（green-700）   | `#85d9a5`（green-300）   |
| 警告       | `#895b0a`（amber-700）   | `#f2c66d`（amber-300）   |
| 说明       | `#2563a6`（blue-700）    | `#91c4ff`（blue-300）    |

对比度（按 WCAG 相对亮度计算）：浅色主色 `#217346` 在白底为 5.82:1，在页面背景为 5.51:1；深色主色 `#85d9a5` 在 `#111814` 上为 10.7:1；次要文字在两种主题分别为 5.14:1 与 8.34:1。全部满足正文 4.5:1。注意 `#85d9a5` 在白底只有 1.68:1，浅色主题下绝不能把它当文字色或图标色。

终端与代码高亮的颜色（`--terminal-*`、`--code-*`）保持独立，官网展示命令片段时使用 `--terminal-background` / `--terminal-foreground`，不借用业务语义色。

## 字体

- **拉丁界面与正文**：Inter，使用 `web/public/fonts/` 中的拉丁子集自托管，`font-display: swap`。
- **命令、路径与代码**：Maple Mono 拉丁字形（同目录子集），保证官网展示的 `webmux run -- claude` 与产品终端里一致。
- **中日韩文字**：系统无衬线栈 `system-ui, -apple-system, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif`，与产品一致，不下载中文字体。
- 字体许可：Inter 与 Maple Mono 为 OFL，复制 `licenses/` 下的许可文本到站点并在页脚“许可”页列出。

排版尺度（桌面 / 手机）：H1 48–56px / 32px，H2 32px / 24px，H3 20px / 18px，正文 16–18px，元数据 14px，命令片段 14–15px。中文正文行高 1.7，英文 1.6；段落最大宽度约 36em（约 70 个汉字），避免长行。标题字重 600，正文 400，不用 300 以下细体。

## 间距、圆角与阴影

- 间距沿用 4px 基准：4 / 8 / 12 / 16 / 24 / 32；区块间距桌面 96px、手机 64px。
- 圆角与产品相同：标签 4px，按钮与输入 6px，卡片与提示 8px，弹层 12px；不用更大的圆角。
- 阴影只用于浮层（菜单、弹窗）；卡片用 1px 边框区分，不叠阴影。
- 控件高度：默认 36px，触屏与小于 640px 时最小 44px。

## Logo 使用

- 横向标志：`webmux-logo-light.svg`（浅底）与 `webmux-logo-dark.svg`（深底），用 `<picture>` 按 `prefers-color-scheme` 切换；最小宽度 120px；四周留白不少于图形高度。
- 单独图标：`web/public/icon.svg` 用于 favicon、`apple-touch-icon`、OG 图与社交头像；不要把横向标志裁成图标。
- 不改色、不加描边、不旋转、不放在渐变或照片上；深色背景只用 `#111814` 或 `#19211c`。
- OG 图模板：1200 × 630，深绿底 `#111814`，左侧薄荷色图标，右侧白色标题与一句副标题；每个主要页面生成各自标题的 OG 图（Astro 可用 satori 或预渲染）。

## 截图与图片

- 只用真实界面：`docs/images/` 下由 `pnpm --dir web screenshots` 生成的图，以及各功能目录中的 PR 证据图；深浅色成对使用。
- 每张图写明 `width` / `height`，导出 AVIF 与 WebP 并保留 PNG / JPG 回退；单张压缩后不超过 200 KB，Hero 主图不超过 300 KB。
- 首屏主图 `loading="eager"` 且 `fetchpriority="high"`，其余懒加载。
- 替代文本描述内容而不是文件名（“会话总览：多个 agent 会话按仓库分组，显示运行状态与屏幕预览”）。
- UI 变化后先在主仓库重新生成截图，再运行同步脚本；官网不手工截图。

## 图标

- UI 图标：Iconify `tabler` 集合，构建期内联 SVG，线宽与尺寸统一（20px 行内、24px 卡片）。装饰图标 `aria-hidden="true"`；纯图标按钮必须有 `aria-label` 与可见提示。
- CLI 品牌：LobeHub 单色 SVG（MIT，来源与版本见 `web/src/icons/lobehub/README.md`），只在“支持的 agent”与 agent 子页使用，附商标声明。
- 不混用 emoji 作为功能图标；README 里的 emoji 卖点在官网改为 Tabler 图标。

## 深色模式与动效

- 跟随系统，提供手动切换并存入 `localStorage`；在 `<head>` 内联一段脚本于首帧前设置 `.dark` 类，避免闪白。
- 过渡 150–200ms，仅用于悬停、展开与主题切换；`prefers-reduced-motion: reduce` 时关闭所有非必要动画。
- 演示视频静音自动循环或改为静态图；不使用自动播放声音与视差滚动。

## 一致性自检

- 页面上出现的每种颜色都能对应到令牌表；每种字号都在排版尺度内。
- 所有按钮只有三种样式：主要（绿色填充）、次要（描边）、文字链接；每个区块只有一个主要按钮。
- 深浅色各截一次首页与下载页，并排比较间距、对比度与截图配对是否正确。
- Logo、favicon、OG 图、PWA 产品图标在视觉上是同一个符号。
