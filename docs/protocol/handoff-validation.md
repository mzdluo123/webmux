# 交接实现与检查

交接采用原生只读范围、默认 Snapcompact 混合归档或显式文本预览，以及普通 prompt 单次发送。
下列条目描述实现与检查入口；实际运行记录见[最新核对记录](../user-stories/verification-log-2026-11-17.md)，不表示本页列出的所有路径已验收。

## 故障矩阵

- 同一预览并发确认：目标创建和 prompt 各得到一次执行权。
- 相同操作重复请求：返回进程内已有结果；修改预览引用产生冲突。
- 来源范围后追加：预览沿用原边界；范围内替换产生来源变化错误。
- 目标原生身份或配置变化：发送在 actor admission 阶段拒绝。
- 准备阶段取消：操作失败；派发后取消观察或断线且无接收证据：unknown，不自动重发。
- 慢模型尚无活动但仍连接：保持 sending，30 秒派发期限不限制 turn 的确认观察。
- 本轮 Agent 活动、授权/提问或成功 prompt 响应：记录 succeeded；仍需单独核对回合结束与答案。
- 超出页数预算：先规划中段分级密度，再显式省略较旧中段范围，首尾保留文本；范围划分同时覆盖文本、图片与省略。
- 缺字、正文覆盖不全或渲染失败：预览带阻止原因，不能发送未覆盖的归档。
- 目标图片能力不支持或发生变化：需要图片时发送拒绝；短历史完整保持文本。
- 图片大小、原始总字节或编码请求超限：预览或发送拒绝，不改用路径引用。
- 归档预览到发送：文本首尾、页序、数量、PNG 字节与 SHA-256 一致；ACP 块顺序为首部、图片、尾部及当前任务。
- 手机编辑预算：逐字删除后可重新输入；无效草稿不发预览请求，也不能发送旧预览。
- token 节省：用同覆盖长历史比较真实模型 usage，单列字段错误、补查费用和内容省略。

## 缓存与生命周期

预览限五分钟、32 项，manifest、文本与图片表示共同计入 64 MiB；操作结果限 256 项、完成后十五分钟。
发送中的 scope 计入预算，缓存清理按请求执行。
服务重启后旧句柄失效；普通 hybrid 恢复以原生 session 身份启动。
旧数据库及 journal/WAL/SHM/lock 保留原件。

## 真实结果的记录口径

每次现场验证分别记录来源读取、PNG 生成、实际 ACP image 块到达、目标答案与 operation 状态。
operation 成功不代表模型读对图片；正确回答也不能把 unknown 状态改写为已确认成功。
独立 CLI/ACP 图片实验保留其原始结果，不代替浏览器 → HTTP → handoff → 目标的端到端证据。
来源版本、身份或 HistoryRoot 发现失败应保留原结果；图片投影修改本身不能证明这些问题已修复。
