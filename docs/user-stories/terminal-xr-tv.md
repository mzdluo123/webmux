# 头显、TV 与沉浸式工作区

本页补充 H 组的跨设备使用故事。操作指南见 [头显与 TV 浏览器](../usage/xr-and-tv.md)。
验收要点描述实现契约，不代表真实硬件已经完成验收；目标头显、TV 遥控器、HTTPS 与系统键盘仍需设备验证。

## H. 头显、TV 与沉浸式操作

- **US-H13 在头显浏览器中使用 2D 工作台**：作为头显使用者，我希望主动选择适合头显窗口与系统键盘的布局，以便不进入 VR 也能操作现有会话。
  验收要点：
  - 终端菜单和设置外观区提供「头显浏览器模式」，仅当前浏览器保存，不靠设备型号猜测；
  - 大窗口不套用手机触屏软键，保留主动「键盘」入口与实体键盘输入；
  - 避免自动聚焦与系统键盘开合导致的重复聚焦、终端 resize 循环；
  - 不要求 WebXR，不创建新 PTY，也不改变现有聊天、代码和 Diff 的权限或生命周期。
- **US-H14 用 TV 浏览器与遥控器操作工作区**：作为电视浏览器使用者，我希望用方向键、确认与返回操作清晰的大目标，以便在远距离阅读和接管服务器任务。
  验收要点：
  - 「TV 模式」可从终端菜单与设置开启，仅当前浏览器保存，增大焦点目标并显示焦点；
  - 方向键进行空间导航，文本编辑、树、菜单等控件保留自身按键语义，可滚动阅读区可导航与滚动；
  - 普通文本框用确认进入/完成编辑，多行内容可用 `Shift+Enter` 换行，结束编辑后仍能用遥控器到达表单按钮；
  - 聊天内联命令菜单先消费返回，再次返回才释放编辑；复制快捷键不误进入编辑，带修饰的按键不落入页面导航；
  - 「终端输入」主动捕获终端按键，返回释放捕获，显式 Esc、Ctrl+C 与滚动按钮不与页面返回混淆；
  - 返回依次处理顶层弹层、输入捕获或编辑、面板与页面，不绕过破坏性操作确认；
  - Git Diff 的显式返回和恢复大小按钮直接切换展示状态，不被查找或缩放面板拦截；分层返回规则只用于 Escape/遥控器 Back；
  - 支持网页而非原生 TV 应用，不承诺系统保留键都能送达网页。
- **US-H15 在沉浸式 VR 中继续现有工作区**：作为支持 WebXR 的头显使用者，我希望把已有终端、聊天、代码和 Diff 放入空间面板，以便保持同一任务上下文。
  验收要点：
  - 使用 HTTPS 或受信任安全上下文，探测 `immersive-vr` 支持，并且只在用户点击「进入 VR」后请求会话；不支持或拒绝时保留 2D；
  - 复用已有 PTY、WebSocket、xterm 缓冲与聊天、代码、Diff 数据，不创建替代服务端会话；
  - 显示会话与面板身份，可切换现有会话、显隐面板，关闭面板不结束会话；
  - 控制器射线及浏览器提供的 gaze / screen 输入使用明确的输入源身份；
  - 拖动和物理缩放不改变终端网格，逻辑行列数另行显式确认，并保留多设备控制权规则；
  - 重叠面板的绘制与射线命中使用同一顺序，真实更近的面板仍保持遮挡优先级；
  - VR 与实体键盘使用共享输入和修饰键状态，提供清除修饰、终端控制键与历史滚动；授权和破坏性操作保持确认；
  - 共享快捷指令更新后，即使 ID 与显示名称不变，VR 也执行最新正文和回车设置，不需要退出重进；
  - 聊天发送失败时保留草稿并在空间面板显示错误，成功重试后清除提示；
  - 不满足切换条件和切换失败的原因在空间面板可见；TUI 中断超时后提供显式返回 2D 的入口，在所属会话中选择等待、强制或取消，不自动强制切换；
  - 终端 Canvas 文字表面不支持图片协议图形，提示返回 2D 查看；复杂表单保留返回 2D 的路径；
  - 设备本地仅保存有界、至多 16 面板的几何与可见性元数据及标识，不复制输出或正文，提供恢复默认布局；
  - 退出、XR 结束或图形上下文丢失恢复 2D，不终止仍在服务端运行的会话，也不新增跨服务重启的持久终端能力。
