# 仓库登记与 worktree 管理

本组记录仓库登记、工作树生命周期、分支维护与独立 Git 工作台的用户故事（US-J01–US-J27），按主题分为两份子文档；代码工作区故事见[代码工作区与工作树](../code-and-worktrees.md)。

- [仓库登记、工作树生命周期与分支维护（US-J01–US-J18）](worktrees/lifecycle.md)：登记与移除仓库、工作树状态与主页显示、新建与检出工作树、安全/强制/批量删除、释放空间与重建、初始化指令、仓库面板同步详情与远程增删改、原地切换分支、获取远程及分支快进/推送/清理。
- [Git 工作台与仓库级接口（US-J19–US-J27）](worktrees/git-workbench.md)：
  - 零会话仓库与工作树级 Git REST API、独立 `/git` 路由与状态隔离、拓扑历史图与任意两版本比较；
  - 真实 `index` 整文件与逐块暂存、高级提交（`Amend`/作者覆盖/`Sign-off`）、全量提交预览与三态复核、三处共享分支动作、~900px 宽幅推送确认框；
  - 持久 Git 操作账本、固定任务审阅基线、跨设备审阅进度与乐观锁草稿及返工交回会话、合并/变基/遴选/还原协调恢复与三方冲突解决器，以及独立 `Stash` 视图、分支/标签/远程维护与单文件历史及 Blame 溯源。
