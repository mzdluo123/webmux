# 终端分屏用户故事

本页延续终端功能组的 US-D13–US-D14，描述会话创建、布局与焦点行为。
完整终端故事索引见[终端操作](terminal.md)。

- **US-D13 分屏操作多个终端**：作为同时处理多个任务的使用者，我希望像 tmux 一样左右或上下拆分终端，以便同时观察和操作多个 Shell 或 agent。
  验收要点：
  - 支持嵌套拆分，最多 8 窗格；
  - 工作区顶栏分别提供文件树与布局入口。布局选择器列出已加入的会话及文件窗格，并提供新建、加入、分屏与关闭窗格。
  - 每个会话只占一个会话窗格；聊天与终端在该窗格内切换，同名会话在选择器中带窗格序号。
  - 可用统一表单新建、快速启动 `/bin/sh -i` 或加入已有会话，同一布局不重复附着；
  - 确认新建、加入或快速分屏时关闭选择器，取消选择时保留当前布局和焦点；
  - 每窗格独立保留终端、聊天、草稿与代码状态；
  - Ctrl+B 后接 %/双引号拆分、方向键/o 切换、z 放大、x 关闭窗格，连续两次 Ctrl+B 传递原键；
  - 输入法、草稿、聊天和弹窗不触发分屏快捷键；
  - 后台窗格不抢焦点或浏览器标题；
  - 只有当前可见窗格显示弹窗，后台切换选择保留至激活后处理。 完整表单支持配置、临时命令、命名和方向选择；
  - 取消不创建，成功保留原终端与路由；
  - 加入已有会话时，候选区保留固定高度，长列表在区内滚动。加载失败后可重试，保留搜索词和分屏方向。在桌面按 Esc 返回原窗格输入；
  - 完整创建和快速 Shell 均保留源启动子目录与工作树校验。 分屏内创建工作树后启动失败，切换仓库再返回仍可选中该树并重试，不重复创建。
- **US-D14 调整并恢复窗格布局**：作为在不同窗口尺寸间工作的使用者，我希望调整、保存和收起窗格，以便保持适合当前任务的工作布局。
  验收要点：
  - 从整条窗格标题栏（包括标题、状态点和工具栏区域）起拖，到目标边缘开分屏，到中央并入标签组；键盘可通过标题栏菜单完成相同操作；
  - 分隔条支持方向键、Home/End 和 Enter；
  - 布局、比例、活动标签和收起状态按会话保存在本机，刷新后恢复，损坏设置回退；
  - 首次恢复旧布局时，合并同一会话的聊天和终端位置，保留其他窗格与可表达的比例。
  - 双击标题栏空白处放大或还原。桌面收起后，文件树默认在左侧、阅读器在右侧、会话窗格在底部保留带名称的边栏标签；可从窗格操作菜单另选边缘。
  - 点击边栏标签可临时查看，其他窗格保持原尺寸。点击外部、再次点击标签或按 Esc 关闭临时查看；点击「固定」将窗格还原到原分组与比例。刷新恢复收起状态和所选边缘，临时查看随刷新关闭。
  - 收起和临时查看保留聊天草稿、阅读位置和终端进程；查看终端不切换混合会话的输入权。
  - 小于 640px 时只显示一个面板，经面板选择器切换；从文件预览返回保留文件树位置，手机切换不覆盖宽屏布局；
  - 关闭窗格只解除连接并保留会话，最后一个关闭后返回列表；
  - 失效会话可收起，终止和移除仍走 US-D10。
