# 终端分屏用户故事

本页延续终端功能组的 US-D13–US-D14，描述会话创建、布局与焦点行为。
完整终端故事索引见[终端操作](terminal.md)。

- **US-D13 分屏操作多个终端**：作为同时处理多个任务的使用者，我希望像 tmux 一样左右或上下拆分终端，以便同时观察和操作多个 Shell 或 agent。
  验收要点：
  - 支持嵌套拆分，最多 8 窗格；
  - 可用统一表单新建、快速启动 `/bin/sh -i` 或加入已有会话，同一布局不重复附着；
  - 每窗格独立保留终端、聊天、草稿与代码状态；
  - Ctrl+B 后接 %/双引号拆分、方向键/o 切换、z 放大、x 关闭窗格，连续两次 Ctrl+B 传递原键；
  - 输入法、草稿、聊天和弹窗不触发分屏快捷键；
  - 后台窗格不抢焦点或浏览器标题；
  - 只有当前可见窗格显示弹窗，后台切换选择保留至激活后处理。 完整表单支持配置、临时命令、命名和方向选择；
  - 取消不创建，成功保留原终端与路由；
  - 完整创建和快速 Shell 均保留源启动子目录与工作树校验。 分屏内创建工作树后启动失败，切换仓库再返回仍可选中该树并重试，不重复创建。
- **US-D14 调整并恢复窗格布局**：作为在不同窗口尺寸间工作的使用者，我希望调整、保存和收起窗格，以便保持适合当前任务的工作布局。
  验收要点：
  - 拖动调整比例，双击等分；
  - 分隔条支持方向键、Home/End 和 Enter；
  - 布局、比例和当前窗格保存在本机，刷新同一入口恢复，损坏设置回退；
  - 窄于 768px 时仅显示当前窗格，宽屏恢复原比例；
  - 放大、切换不销毁其他窗格；
  - 关闭窗格只解除连接并保留会话，最后一个关闭后返回列表；
  - 失效会话可收起，终止和移除仍走 US-D10。
