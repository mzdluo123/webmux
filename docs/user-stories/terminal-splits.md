# 终端分屏用户故事

本页延续终端功能组的 US-D13–US-D14，描述会话创建、布局与焦点行为。
完整终端故事索引见[终端操作](terminal.md)。

- **US-D13 分屏操作多个终端**：作为同时处理多个任务的使用者，我希望像 tmux 一样左右或上下拆分终端，以便同时观察和操作多个 Shell 或 agent。
  验收要点：
  - 支持嵌套拆分，最多 8 窗格；
  - 工作区顶栏分别提供文件树与布局入口。布局选择器列出已加入的会话及文件窗格，并提供新建、加入与关闭窗格。桌面提供分屏方向；手机提供「快速新建 Shell」，新窗格占据当前视图。
  - 每个会话只占一个会话窗格；聊天与终端在该窗格内切换，同名会话在选择器中带窗格序号。
  - 可用统一表单新建、快速启动服务端默认登录 Shell 或加入已有会话，同一布局不重复附着；
  - 确认新建、加入或快速分屏时关闭选择器，取消选择时保留当前布局和焦点；
  - 每窗格独立保留终端、聊天、草稿与代码状态；
  - Ctrl+B 后接 %/双引号拆分、方向键/o 切换、z 放大、x 关闭窗格，连续两次 Ctrl+B 传递原键；
  - 输入法、草稿、聊天和弹窗不触发分屏快捷键；
  - 同时显示多个窗格时，主题色边框随点击或键盘焦点移动到当前窗格。只显示一个窗格时隐藏边框，包括放大、收起其他窗格、单一标签组和手机布局；
  - 后台窗格不抢焦点或浏览器标题；
  - 只有当前可见窗格显示弹窗，后台切换选择保留至激活后处理。 完整表单支持配置、临时命令、命名和方向选择；
  - 取消不创建，成功保留原终端与路由；
  - 加入已有会话时，候选区保留固定高度，长列表在区内滚动。加载失败后可重试，保留搜索词和分屏方向。在桌面按 Esc 返回原窗格输入；
  - 已有会话列表上方使用通栏搜索，聚焦时底线高亮。
  - 完整创建和快速 Shell 均保留源启动子目录与工作树校验。 分屏内创建工作树后启动失败，切换仓库再返回仍可选中该树并重试，不重复创建。
- **US-D14 调整并恢复窗格布局**：作为在不同窗口尺寸间工作的使用者，我希望调整、保存和收起窗格，以便保持适合当前任务的工作布局。
  验收要点：
  - 会话和 Git 工作台的每个窗格右上角提供「⋮」和「−」。前者列出适用于此窗格的布局操作，后者直接收起；收起保留内容，可以重新打开。
  - 桌面可从整条窗格标题栏起拖，包括标题、状态点和工具栏区域。有其他窗格可停靠时，工作区四周显示整体停靠标记；指针移到另一窗格后，该窗格中央显示十字标记。
  - 将指针移到标记上可预览落点。松开工作区边缘标记，窗格停靠到整个工作区的对应一侧；松开十字的方向标记，仅拆分目标窗格；松开十字中央标记，合为标签组。
  - 不使用标记时，仍可拖到目标窗格边缘开分屏、到中央并为标签；键盘也可通过工作区顶栏的「窗格」菜单拆分目标组或合为标签。按 Esc 取消拖动，标记和预览消失，布局保持不变。
  - 分隔条支持方向键、Home/End 和 Enter；
  - 同一设备上的终端、聊天、文件树、阅读器与堆叠窗格共用标题栏高度；鼠标桌面采用标准控件高度，触屏或手机采用较高的触控尺寸并随字号缩放。切换窗格内容不改变正文起始高度。
  - 同组窗格各自显示内容类型图标；文件与会话共享同一排标签。当前标签底部的细线覆盖标题和关闭按钮，两侧等距内缩。切换后自动出现在标签栏可视范围内，支持点击及方向键切换。
  - 文件标签右侧的 × 关闭对应文档；会话标签的 × 仅收起窗格，终端会话继续运行。关闭当前标签会切换到相邻标签，关闭后台标签则保留当前视图。
  - 桌面顶栏「窗格」菜单显示操作目标；打开后放大、还原、收起、移动或合并都作用于该目标。「关闭窗格」始终列出：关闭文档只移除该文件，关闭终端或聊天保留会话进程，关闭文件树可从边栏恢复。手机在「打开面板」抽屉中收起当前窗格。
  - 布局、比例、活动标签和收起状态按会话保存在本机，刷新后恢复，损坏设置回退；
  - 首次恢复旧布局时，合并同一会话的聊天和终端位置，保留其他窗格与可表达的比例。
  - 双击标题栏空白处放大或还原。桌面会话工作区收起窗格后，在其停靠一侧的边栏显示带名称的标签：贴左侧入左栏、贴右侧入右栏、贴底横跨的入底栏；不贴边的窗格按类型默认（文件树左侧、阅读器右侧、会话窗格底部），可从窗格操作菜单另选边缘。
  - 会话和 Git 工作台还原到多窗格视图后，当前窗格重新显示焦点边框。
  - 拖动边栏标签到另一个窗格可重新分屏或并为标签组；松开鼠标后窗格在目标位置展开。点击边栏标签直接恢复窗格原有的分组、位置和比例，标签随即消失。切换焦点或按 Esc 后，窗格仍保持展开。
  - 刷新后恢复窗格的展开或收起状态。再次收起时按当前停靠位置选择边栏，未贴边的窗格沿用上次的边栏；Git 工作台沿用原有收起与恢复入口。
  - 收起和恢复保留聊天草稿、阅读位置和终端进程；布局操作不切换混合会话的输入权。
  - 小于 640px 时只显示一个面板，经面板选择器切换；从文件预览返回保留文件树位置，手机切换不覆盖宽屏布局；
  - 关闭窗格只解除连接并保留会话，最后一个关闭后返回列表；
  - 失效会话可收起，终止和移除仍走 US-D10。
