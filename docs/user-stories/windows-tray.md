# Windows/WSL 托盘

本页从[原生客户端、隧道与托盘](clients-network-tray.md)拆出，描述 O 组故事；M、N、P 组仍在原页面。

## O. Windows/WSL 托盘管理

| 编号 / 功能                        | User story                                                                                                                                         | 验收要点                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| US-O01 安装或升级 WSL 服务         | 作为 Windows 使用者，我希望从托盘安装或升级 WSL 中的 WebMux，并在开启自动更新时让较旧的服务自动跟上托盘，以便减少手工下载步骤。                    | WSL 中的 webmux 缺失、缺少本机 API、控制契约过旧或版本低于托盘时提供入口；WSL 2 与发行版可用时选择匹配架构和托盘版本；校验发布时嵌入的服务摘要才安装；托盘下载缓存中已有同版本且摘要匹配的文件（包括 Windows 安装程序预置的服务端）时直接安装、不联网，摘要不符时丢弃并重新下载；支持 GitHub 与镜像回退；缺失时从不在后台安装；发布构建且开启“自动更新”时，检查发现较旧或契约过旧（含缺少本机 API）即自动升级，失败在状态行显示“自动升级 WSL 中的 webmux 失败：…”且到下次检查时机才重试，过新或无法判断时不自动改写；普通本地托盘构建无摘要时不提供安装；运行中的旧服务到重启才更新。                                                                                                                                                                                                                                                                                                                                                                         |
| US-O02 启动方式与恢复              | 作为 Windows 使用者，我希望托盘管理 WebMux 的启动和故障恢复，以便无需一直开着 WSL 窗口。                                                           | 可选 auto、tray、systemd；auto 优先已有可用用户服务，否则托盘托管；按方式保持 WSL 存活；托盘托管意外退出后退避重启，10 分钟内最多 5 次；systemd 重启策略交给单元。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| US-O03 管理所属实例                | 作为 Windows 使用者，我希望托盘区分自己管理的服务和外部实例，以便不误停其他终端启动的工作。                                                        | 可启动、停止、重启所属实例；有会话的停止、重启或切换目标先确认；外部或启动方式不符的实例只提供访问操作；不擅自接管停止权限。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| US-O04 登录启动与单实例            | 作为 Windows 使用者，我希望登录后出现一个托盘实例，以便随时找到服务入口。                                                                          | 同一 Windows 用户只运行一个托盘，再次启动通知已有实例；可选择注册当前 exe 为登录启动；exe 移动后需重新登记；安装程序可登记同一启动项，复选项随之显示为已勾选；`webmux-tray.exe quit` 请求已运行的托盘按“仅退出托盘”退出且不询问，退出码 0 表示已退出或未运行、1 表示仍在运行、2 表示参数错误，`--kill-path` 超时后只结束当前用户从该路径运行的托盘；无需以管理员启动托盘。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| US-O05 选择发行版与编辑设置        | 作为 Windows 使用者，我希望选择 WSL 发行版、启动方式和路径，以便使用自己配置的开发环境。                                                           | 设置写入 `%APPDATA%\WebMux\tray.json`，保存后自动重载；无效文件提示并使用默认值，不覆盖文件；提供打开 WebMux 配置与托盘设置入口；配置缺失才提供初始化，已有配置不被自动改写。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| US-O06 查看状态和日志              | 作为 Windows 使用者，我希望托盘图标、菜单和日志解释运行问题，以便判断该重启还是修正配置。                                                          | 区分运行、启动、停止和错误；提示 WSL 缺失、版本不兼容（见 US-O11）、配置及健康错误；可打开服务日志或 systemd journal 和托盘日志；托盘日志轮转且不记录 token。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| US-O07 诊断 Windows 可达性         | 作为 Windows 使用者，我希望知道 WSL 内服务健康但 Windows 仍无法连接的情况，以便定位网络模式或 localhost 转发问题。                                 | 独立从 Windows 回环地址检查可达性，不带 token 且不走系统代理；故障时提示 localhostForwarding/networkingMode；不把 WSL 内健康等同于 Windows 浏览器可达。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| US-O08 转发可信远程地址            | 作为 Windows 使用者，我希望在 NAT 模式下通过选定的主机地址访问 WSL 服务，以便从手机继续操作。                                                      | 转发默认关闭，Tailscale 地址优先展示；仅服务健康、配置 token 且 Windows 可达时监听，条件失效暂停、恢复后继续；转发 HTTP 与 WebSocket 并校验地址对应 Host/Origin；保存地址选择并报告端口冲突，退出托盘即停止；不自动修改防火墙。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| US-O09 打开和复制受保护入口        | 作为 Windows 使用者，我希望从托盘打开页面、在统一的“复制链接”子菜单中复制本机/远程/经托盘转发/公网链接，或复制 token，以便把访问入口带到另一设备。 | 操作时从 WSL 获取 token，不在 Windows 配置中保存；复制链接可带 `#token=`，不配置 token 时复制普通链接；仅服务明确返回 `settingsAvailable: true` 时提供“公网访问设置”，打开本机 `/settings/tunnel` 并沿用 token 片段交接；敏感剪贴板排除历史和云同步，60 秒后仅在内容未被替换时清空；通知只显示无 token 地址。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| US-O10 退出托盘保留任务            | 作为 Windows 使用者，我希望只退出托盘而保留 WebMux，以便临时关闭桌面客户端却不中断任务。                                                           | “仅退出托盘”不停止服务，重新打开后恢复可用控制；托盘转发随退出停止；Windows 注销或关机不承诺保留任务；需要停服务时使用单独停止操作。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| US-O11 判断 WSL 服务兼容与版本对应 | 作为 Windows 使用者，我希望托盘告诉我它与 WSL 中的 webmux 是否兼容、版本是否对应、该更新哪一边，以便两边分别升级后不再遇到含糊的失败。             | 托盘启动后首次取得状态、切换发行版或修改 `webmux` 路径、安装完成后，以及处于缺失或不兼容状态时打开菜单，在后台以 `version --json` 检查（旧版本回退文本并视为契约 v1），单次不超过 30 秒，日志记录两侧版本与契约；兼容只看控制契约，对应只比较版本号，`dev` 等非发布版本无法判断且不提示；结果只出现在菜单状态行，不发通知或弹窗：较旧一方、“比托盘新，请升级托盘”或“版本过旧，请升级”；WSL 较新且为发布版本时，安装版托盘提供“更新托盘”（开启自动更新时自动检查一次，见 US-O13），便携版提供“下载托盘 <版本>”打开 Release 页面；契约不兼容仍可启动、停止、重启，以 Windows 侧可达性判断运行并显示“运行中（不兼容，功能受限）”，状态无法解析不判失败、不自动重启；缺少本机 API 时禁用启动；运行实例与已安装文件版本不同时提示重启后生效，只有托盘管理的实例可从菜单重启。                                                                                                                                                                                      |
| US-O12 用安装程序安装与卸载托盘    | 作为 Windows 使用者，我希望用安装程序安装、升级和卸载托盘，以便获得固定位置、开始菜单入口和卸载项，而不必手工放置 exe。                            | `webmux-setup-windows-<架构>.exe` 按当前用户安装、不需要管理员，默认目录 `%LOCALAPPDATA%\Programs\WebMux`（可更改，升级沿用上次目录）；安装 `webmux-tray.exe`、开始菜单“WebMux”与“应用和功能”卸载项（名称、版本、发布者）；“安装选项”页的“开机后自动启动 WebMux”默认勾选，写入与托盘菜单“登录时自动启动”相同的启动项；预置同架构 Linux 服务端到托盘下载缓存，不访问或改动 WSL；安装包架构与 Windows 不符时提示正确的安装包并以退出码 2 退出，不写任何文件；覆盖安装先以 `quit` 关闭本用户托盘（WebMux 与会话保持），安装目录中的托盘 10 秒无响应才强制结束，其他位置不响应的托盘只提示用户退出并可重试，静默模式以退出码 3 结束且不写文件；完成后启动托盘；卸载同样先关闭托盘，删除程序、快捷方式、卸载项与预置服务端，登录启动项仅在指向本次安装时删除，保留托盘设置、日志与 WSL 中的 webmux，不停止 WebMux；支持 `/S` 静默安装与卸载：首次安装用默认选项，覆盖安装沿用登记的安装目录并保持登录启动项现状，关闭托盘后失败时重新启动原托盘并以退出码 4 结束。 |
| US-O13 托盘自动更新                | 作为用安装程序安装托盘的 Windows 使用者，我希望托盘自己安装经过签名验证的新版本，且不结束 WSL 中的终端会话，以便不必手动下载安装程序。             | 托盘设置 `autoUpdate` 默认开启（旧设置缺省视为开启），菜单提供“自动更新”勾选项与随时可用的“检查更新”，非发布构建禁用并说明原因；开启时启动 2 分钟后检查、之后每 24 小时检查，读取签名清单（GitHub 与镜像，只信内置公钥）；从登记的安装目录运行的安装版发现更高版本时下载同架构安装程序到 `%LOCALAPPDATA%\WebMux\updates` 并校验，等无 WSL 安装、启停重启或对话框时以分离进程运行 `/S`，旧托盘按“仅退出托盘”退出，WebMux PID 与会话不变、转发在新托盘恢复；关闭自动更新时只提示“有新版本”并提供“更新到 <版本>”；便携版只提示并提供“下载托盘 <版本>”，从不下载；失败显示“更新失败：<原因>”，下次计划检查重试；不发系统通知；新托盘按 `lastVersion` 显示一次“已更新到 <版本>”并清理下载目录。                                                                                                                                                                                                                                                                    |

隧道设置的增量兼容同样归入 US-O11：不得从版本号或存在 `tunnel` 字段推断设置页可用，只有 `settingsAvailable: true` 才显示入口；缺少该字段的旧服务仍保留原有隧道控制。可选 `enabled` 表示当前进程期望（包括 `--tunnel` 覆盖），不是持久磁盘值；缺失时才按 starting/ready 推断开关。

Windows 原生终端客户端复用 US-M01–US-M06：提供 run、attach、ls、open、status 与 version，服务仍在 WSL 中。

- 发行版与 webmux 路径：按命令行、环境变量、托盘设置、默认值依次解析。
- 路径换算：用 `wslpath` 换算盘符路径，识别同发行版的 WSL UNC 路径，无法换算时要求显式 Linux `--cwd`。
- 连接：经 `wsl.exe --exec webmux bridge`，不依赖 localhost 转发。
- 附着：使用 UTF-8/VT 控制台，恢复后还原模式与代码页。
