# 头显与 TV 工作区

本页补充 H 组的跨设备使用故事。操作指南见 [头显与 TV 浏览器](../usage/headset-and-tv.md)。
验收要点描述实现契约，不代表真实硬件已经完成验收；目标头显、TV 遥控器与系统键盘仍需设备验证。

## H. 头显与 TV 操作

- **US-H13 在头显浏览器中使用 2D 工作台**：作为头显使用者，我希望主动选择适合头显窗口与系统键盘的布局，以便操作现有会话。
  验收要点：
  - 终端菜单和设置外观区提供「头显浏览器模式」，仅当前浏览器保存，不靠设备型号猜测；
  - 大窗口不套用手机触屏软键，保留主动「键盘」入口与实体键盘输入；
  - 避免自动聚焦与系统键盘开合导致的重复聚焦、终端 resize 循环；
  - 不创建新 PTY，也不改变现有聊天、代码和 Diff 的权限或生命周期。
- **US-H14 用 TV 浏览器与遥控器操作工作区**：作为电视浏览器使用者，我希望用方向键、确认与返回操作清晰的大目标，以便在远距离阅读和接管服务器任务。
  验收要点：
  - 「TV 模式」可从终端菜单与设置开启，仅当前浏览器保存，增大焦点目标并显示焦点；
  - 方向键进行空间导航，文本编辑、树、菜单等控件保留自身按键语义（内联 `radiogroup`/`tablist`/`listbox` 在首尾边界遇到同行或同列相邻控件时可向该相邻控件移出焦点），可滚动阅读区可导航与滚动；
  - 普通文本框用确认进入/完成编辑，多行内容可用 `Shift+Enter` 换行，结束编辑后仍能用遥控器到达表单按钮；
  - 聊天内联命令菜单先消费返回，再次返回才释放编辑；复制快捷键不误进入编辑，带修饰的按键不落入页面导航；
  - 「终端输入」主动捕获终端按键，返回释放捕获，显式 Esc、Ctrl+C 与滚动按钮不与页面返回混淆；
  - 返回依次处理顶层弹层、输入捕获或编辑、面板与页面，不绕过破坏性操作确认；
  - Git Diff 底部停靠栏通过收起/展开按钮与键盘可调高度分隔条（`code-row-divider`）调整阅读区域，手机分步视图的显式返回按钮直接切换步骤且不被查找或缩放面板拦截；分层返回规则只用于 Escape/遥控器 Back（先关闭阅读面板，再退手机 Diff/详情步骤，最后退路由）；
  - 支持网页而非原生 TV 应用，不承诺系统保留键都能送达网页。
- **US-H15 在沉浸式 VR 中继续现有工作区（已退役）**：作为支持 WebXR 的头显使用者，我曾希望同时观察多个会话，并把同一聊天拆成独立的历史与最新视图。
  - 已退役（2026-11-17）：沉浸式 VR 工作台及 `immersive` 功能项已移除；头显 2D 与 TV 浏览器工作流分别由 US-H13、US-H14 继续覆盖。
