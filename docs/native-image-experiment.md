# 原生历史图片传输实验

当前生成器比较原文、同覆盖投影文本与 Snapcompact 首尾文本/中段图片归档。
2026-11-18 的工具/代码样本保留 102586 个投影字符，实测输入 token 减少 40.6%；长段落样本减少 15.4%。
两个样本均无预算省略，13 个精确字段全部正确，没有补查请求。
生产交接规则见[交接操作](hybrid-sessions/handoff.md)。本页后半保留 v0.1.0 的历史实验结果。

## 复现与安全边界

需要仓库指定的 Go 工具链、Python 3，以及已正常认证的 omp。运行会向模型发送合成数据，可能消耗额度或产生费用。
从仓库根目录执行：

```sh
out=$(mktemp -d /tmp/webmux-image-experiment.XXXXXX)
go run ./cmd/native-image-experiment \
  -scenario tools -model openai-codex/gpt-6-astra -history-cap 64000 "$out"
python3 cmd/native-image-experiment/run.py "$out" \
  --backend omp --model openai-codex/gpt-6-astra \
  --modes projected archive --readback --timeout 240
```

[生成器](../cmd/native-image-experiment/main.go)直接引用 `go.mod` 已锁定的独立模块，没有复制渲染核心。
[CLI runner](../cmd/native-image-experiment/run.py)输出逐次报告；`-scenario long` 使用长段落，`-scenario small` 使用短样本；`--backend codex` 可探测 Codex。
模型 ID 及认证是否可用由当前 CLI 决定；不能把实验所用账号的可用性当作发布保证。

- 历史只包含确定性合成记录，不读取私人历史或认证内容，不连接开发服务，不修改用户配置。
- 每次请求使用新的临时 cwd；omp 禁用工具、扩展、skills、rules、上下文文件、LSP、标题生成和会话持久化，并限制辅助服务。
- omp 每次调用默认使用 `$2` 软成本上限及超时；`--max-cost` 可调整，正在执行的请求可能超过软门槛。
- Codex 使用 `--ignore-user-config --ignore-rules --ephemeral --sandbox read-only --skip-git-repo-check`，不恢复旧会话；这不等同于禁用其全部内置工具。
- CLI 正常使用已有认证。认证失效时停止该后端，不读取或搬运凭据、不自动登录、不改认证配置。
- 生成物和原始 CLI 输出留在临时目录；报告权限为 `0600`，临时 cwd 在每次请求后清理。保留结果目录供复核，分享前检查原始输出。
- 生成物与逐次输出留在临时目录；仓库保存[归档实测数据](../cmd/native-image-experiment/archive-measurements.json)与[历史数据](../cmd/native-image-experiment/measurements.json)。

## 2026-11-18：上游式混合归档

渲染核心固定为 `snapcompact-go` 提交 `969040513d9e`；使用 omp 18.22.0、`openai-codex/gpt-6-astra`。
按上游模型几何与点阵布局保留首尾文本，中段使用高密度图片，超出容量时先分级密度再显式省略。
实验的 `projected.txt` 与归档保留序列完全相同，来源序号映射也相同；任何预算省略、缺字或未覆盖范围均使生成失败。

| 合成样本   | 投影字符 | 记录数 | 文本输入 token | 归档输入 token |  节省 |
| ---------- | -------: | -----: | -------------: | -------------: | ----: |
| 长段落     |   102237 |    148 |          30312 |          25659 | 15.4% |
| 工具与代码 |   102586 |    124 |          43506 |          25857 | 40.6% |

- 每种表示各调用一次；两组均 13/13 字段正确，包含早期约束、各位置随机标记、中文、代码缩进、Shell 标点及最新修正。
- 两组均无工具调用或补查。`--readback` 仅对明确返回 `NEED_SOURCE` 的字段补充最多三条、6000 字符原文，并单列第二次调用费用；本次没有触发。
- CLI 报告的总费用：长段落文本 `$0.31427`、归档 `$0.27364`；工具/代码文本 `$0.44641`、归档 `$0.27467`。这是 CLI 目录估计，未核验账单。
- 每次调用只读取一个最终 usage 快照；输入计数包含缓存与系统开销，未叠加流式事件。
- 使用 64000 历史预算以保持完整覆盖；生产默认 `handoff_token_cap=16000` 仍有效，大历史需要显式提高预算。更大样本曾因 23 个省略范围被生成器拒绝，没有把删除内容计为压缩收益。
- 机械投影会规范化空白；两组原始正文分别为 102239、102587 字符。表格比较规范化后的同覆盖正文，不宣称原始字节完全不变。
- 只覆盖此模型和合成样本，没有置信区间；CLI 附件路径未验证真实 ACP 网关计费。浏览器与 ACP 内容顺序由独立集成回归覆盖。

## 历史实验：v0.1.0

以下记录来自 2026-11-15 的四条合成中文历史；当时完整历史图片比同覆盖投影文本更贵。
对应生成器与旧模式保留在提交历史中，当前命令使用上述归档模式。

## 样本与评分

样本覆盖中文、代码缩进、`<=`/`!=`、Shell 引号及 `| && ; $()`、240 行长日志和用户中途修正。
命令只是字符样本，实际没有执行。当前任务始终独立保留为文本。

| 表示      | 历史输入                                 | 当前任务 |
| --------- | ---------------------------------------- | -------- |
| raw       | 原始四条记录文本                         | 独立文本 |
| projected | 默认机械预处理后的同一历史               | 同上     |
| image     | 同一完整投影的三张图片                   | 同上     |
| hybrid    | 前三条投影的两张图片，最后一条修正为文本 | 同上     |

采用模块默认规则：工具输出 2000 rune、参数 500 rune、调用体 2000 rune、首部 60%。
原文日志长 9910 rune，省略区间为 `log.text[1200:9110)`；生成的 manifest 保存原文范围、投影和页映射。
原始历史 12251 字节，投影历史 3181 字节；这里的字节数不是 token。

任务逐字段核对六项可见事实：修正后的端口、中文、Python 条件、首个 return 的八空格缩进、完整命令标点和日志尾标记。
另外询问被截断的中段标记：原文应返回 `JADE-120`，其他表示应明确返回 `NEED_SOURCE`，不猜测。
因此报告中的七项正确包含“正确发现缺失”，不表示投影恢复了全部原文。

## 实测结果

测量时间为 2026-11-15 18:34 UTC（北京时间 11 月 16 日），macOS arm64，omp `18.20.2`。
每种表示只运行一次最终七字段任务；每次新会话只发生一次回答，无工具调用，无补查请求。
另有一次六字段的预探测，不混入下表。耗时包含 CLI 启动、请求和响应，不是纯模型推理时间。

| 表示      | 输入 token | 输出 token | 总 token | CLI 估价 USD | 耗时秒 |
| --------- | ---------- | ---------- | -------- | ------------ | ------ |
| raw       | 5484       | 77         | 5561     | 0.011738     | 4.911  |
| projected | 2696       | 76         | 2772     | 0.006152     | 4.492  |
| image     | 4722       | 150        | 4872     | 0.010944     | 10.117 |
| hybrid    | 4254       | 137        | 4391     | 0.009878     | 7.262  |

这些 token 来自真实模型调用完成后的 CLI usage，不是本地 tokenizer 或 PNG 大小估算。
CLI 报告缓存读写均为零；image/hybrid 的输出分别包含 72/59 个 reasoning token，不再次加到总数。
USD 是 CLI 模型价格表计算的估价，不是支付账单，未独立核验网关最终收费或订阅额度折算。
原始事件中同一 usage 在多个结束事件重复出现，取最后一次完整 usage，不能累加这些快照，也不能把初始全零 usage 当作免费。

四种表示的六项可见事实均精确正确，读取错误 0、端口修正遗漏 0。
只有 raw 返回中段原始标记，其余均返回 `NEED_SOURCE`；补查次数为 0，不把缺失检测算作已完成原文补查。
因此本表也是该“读取可见事实并报告缺失”任务的总输入/输出，不是恢复全部原始事实任务的完成成本。
若要求恢复中段原文，仍需冻结来源精确读取和追加模型请求；该完整任务的总费用、补查延迟与成功率尚未知。

同覆盖内容比较应看 projected/image/hybrid：图片和混合表示的输入 token、总 token、估价、延迟都高于投影文本。
raw 与 projected 的差异同时包含机械截断及空白规范化，不能归功于图片，也不能称为无损节省。
这是单样本单轮观察，不足以推广到其他文本密度、模型或网关。

## 图片确实进入了哪一层

image 模式的用户文本只有任务、附件文件包装和缩放坐标说明，不包含上述六项答案。
CLI 的 user `message_end` 包含三个真实 `image` 块；模型在无工具调用情况下返回了只存在于图片中的中文、命令及代码缩进。
这不是只生成 PNG、发送一个文件路径或使用 fake agent 的证据。

模块使用默认 18px 字号、28px 行高、16px padding、1024×1024 页框，缺字数与未覆盖范围均为 0。
生成的 image 页为 1024×1012、1024×1012、1024×116；hybrid 为 1024×1012、1024×984。
omp 事件中的附件经过实际变换：

- image：两张 WebP，分别 68592/81336 字节、均为 1024×1012；最后一张 PNG 54307 字节、1568×200。
- hybrid：两张 WebP，68592/79586 字节，分别为 1024×1012、1024×984。
- 矮页被放大并补边；CLI 文本明确报告原尺寸 1024×116、显示尺寸 1568×200 和 padding 坐标转换。
- 尺寸从 CLI 事件内图片数据头解析，不是网络抓包；不能据此证明后续网关或模型内部没有其他变换。

本次本地 Project 为 0.380ms，image/hybrid Render 为 37.395/28.562ms。
Render 计时包含本实验的页文件写入，排除字体初始化和编译；没有测峰值 RSS，不替代独立核心的内存基准。

## 兼容性、阻塞与文本回退

已查阅本机 Codex `0.165.0`、Claude Code `2.1.245`、omp `18.20.2` 和 OpenCode `1.18.23` 的帮助。
Codex 有 `exec --image`，omp 接受 `@image.png`，Claude 有 `--input-format stream-json`，OpenCode 有 `run --file`。
参数存在不证明模型可读；后两者仅查帮助，没有真实图片成功记录。

Codex 隔离的原文探测在 60.407 秒后以 1 退出，最小阻塞证据为 `401 token_revoked` 及 `workspace routing discovery unauthorized (401)`。
没有到达图片请求阶段，没有 usage；费用与图片支持均未知。恢复该组合需要账号所有者修复正常 CLI 认证，本实验未执行登录或配置变更。
omp 使用自己的已配置 provider 正常成功，不把 Codex 的认证失败外推为 omp 或模型不支持图片。

尚未测定模型/网关的最大图片数、detail、像素上限、请求体上限，也未独立验证最终计费规则；只确认本次 3 图/2 图输入可完成上述读取。
没有通过 WebMux/ACP 或原生历史注入接口发送，不把这条 CLI 证据写成 WebMux 端到端交接已经支持图片。
实验时的[原生历史开发入口](codex-native.md)只负责导入、冻结、机械投影和渲染。
当时对未实测组合、缺字/覆盖不全、能力或成本未知情况保留文本，并因未显示成本优势而不建议默认转图。
这些结论保留其历史范围；当前图片交接遇到上述阻止条件时要求用户重新选择格式并预览，没有静默文本回退。
