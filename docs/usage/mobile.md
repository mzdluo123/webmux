# 移动端使用

- 软键栏在带触摸屏的设备（手机、平板，包括连接手写笔或键盘时）上默认显示，提供 `⌨`（唤起 / 收起键盘）、粘贴、`/`、`@`、`#`、`!`、Esc、Tab、Ctrl、Alt、Shift、方向键、Home/End、PgUp/PgDn 以及 Ctrl+C/D/Z/L/R。
  - Ctrl / Alt 为一次性修饰键。
  - Shift 点按为一次性，长按约 0.5 秒锁定，再次点按解除，锁定时按钮显示锁图标，标题提示解除方式。
  - Shift 可与 Tab、方向键及 Home/End、PgUp/PgDn 组合发送带 Shift 的按键序列。
  - 点按或锁定后，虚拟与实体键盘的后续输入（字母、符号及这些功能键）同样应用 Shift。符号映射按 US 布局，其他布局的字符未在映射中时保持原样。

- 在触摸屏设备上，只有点击 `⌨` 才会唤起虚拟键盘：进入终端、轻点或用手写笔点击终端、开启草稿、关闭弹窗、上传完成都不会自动聚焦输入。
  - 键盘已弹出时，方向键、Esc、Tab 等发送软键保持焦点、不收起键盘；快捷指令菜单和粘贴弹窗会把焦点转入弹层。
  - 用 Android 系统返回键收起键盘后，再轻点、滑动或笔点终端也不会重新弹出；此时点击 `⌨` 可重新唤起。

- 单指滑动滚动历史（全屏 TUI 中转换为滚轮事件）；双指捏合被忽略，不改变字号、终端行列或浏览器页面缩放，避免误触。
- 终端菜单可开启“锁定尺寸”。锁定后软键盘、浏览器地址栏、窗口或旋转引起的宽高变化都不会改变 PTY 行列，终端按锁定时的网格显示；网格宽或高超出可用区域时只显示一条滚动条，默认贴住底部使最新输出和输入行可见，可滚动查看被挡住的部分。锁定时调整字号只缩放显示、不改变行列；关闭锁定后按当前可见视口重新适配。
- 用底部工具栏的 `⌨` 唤起软键盘时，终端默认暂时保持行列不变，避免全屏程序因键盘开合整屏重绘。
  - 保持期间的显示与“锁定尺寸”相同：默认贴底，最新输出和输入行留在键盘上方，被挡住的部分可滚动查看。
  - 键盘无论用 `⌨` 还是系统方式（返回键、输入法收起键、iOS“完成”）收起，都在收起动画结束后恢复正常适配；开合一次不改变 PTY 尺寸。
  - 焦点转到粘贴弹窗、查找栏等其他输入框而键盘仍显示时，保持不结束，等键盘真正收起后再适配。
  - 保持期间旋转、调整宽度或字号仍立即适配；约 1.5 秒内没有弹出键盘（如连接实体键盘）时自动结束。
  - 在终端菜单取消“键盘弹出时保持尺寸”可恢复随键盘实时适配，该选择保存在本机浏览器并对所有会话生效。
- 长按约 0.5 秒选中词语，继续拖动可跨行扩选，然后点击“复制选中”。
- 支持浏览器原生全屏，也可“添加到主屏幕”以独立模式运行。iPhone 不支持网页全屏：Safari 标签页中的“全屏”会提示添加到主屏幕，主屏幕 Web App 中不显示该入口。
- 窄屏触摸设备上，图片工具栏只保留“适应窗口”和“1:1”，用双指缩放图片。
- 终端输入关闭了自动大写、拼写检查和自动纠正。

Chromium 移动模拟不能完全代替真机。iOS Safari / Android 的输入法、系统键盘和锁屏恢复行为请以真机为准。
