# 仓库与 worktree

需要系统安装 Git；没有 Git 时终端功能不受影响。

## 登记与创建

- **添加仓库**只登记已有仓库，不会 clone 或 init。登记信息在服务重启后保留。
- 仓库标题栏的 **新建工作树** 默认只创建工作树，可创建新分支或检出未被占用的本地分支。默认位于仓库旁的 `<仓库名>.worktrees/<分支名末段>`，不会复制 `.env` 或安装依赖。
  - 创建新分支时可选择起始分支（下拉框，按最近提交时间从新到旧排列），默认是主工作区当前本地分支。选择后异步 fetch 其已配置上游；仅当本地尖端是上游提交的祖先时，默认使用上游最新提交的精确 OID。本地领先或分叉时保留本地提交；无上游或刷新失败时也保留本地基线。
  - "起始提交"是下拉框，列出所选分支最近 50 条提交（超出上限的起始提交仍会列出），无需输入提交 ID：
    - 每行先显示提交标题，下方是短哈希、"本地最新"/"远程最新"标记和相对时间；
    - 点击"刷新上游"会 fetch 并把上游最新提交合并进列表；本地领先或分叉、默认仍保留本地提交时，也可直接选择远程最新；
    - 刷新动画不阻塞字段编辑或创建；刷新期间确认创建会使用当前可见基线；
    - 切换分支或手动选择其他提交后，晚到响应不会覆盖较新的选择。
  - 使用已有分支时不自动 fetch，也不会改用其上游提交。
- 勾选 **创建后启动会话** 才显示命令并启动；不勾选时不要求启动配置。同一工作树可新建多个会话，它们**共享同一份文件**。
- **关闭会话**不会删除工作树；**从列表移除仓库**只移除登记，不删除目录或分支。

## 删除与保护

- **删除 worktree** 先预览，默认拒绝存在未提交修改、未跟踪 / 忽略文件或活动会话的工作树。主工作区、bare、locked 及含子模块的工作树不能通过页面删除。
- 预览会列出该目录下已归档（已关闭或已中断）的混合会话。删除成功后，这些记录（强制删除时关闭的混合会话留下的也一样）保留并标为已释放：
  - 记录出现在仓库的“已不可用工作区”，点击后先确认在原路径按提交重建工作树，再恢复；
  - 工作树里未提交、未跟踪与忽略文件仍不保留，只保留提交；
  - HEAD 无法解析（例如还没有提交）时无法保存提交，记录保持原样、只能查看或手动删除，但不阻止删除。
- 预览与释放空间对话框还会检查要保留的提交是否已推送：只读本地远程跟踪引用，不联网。
  - 尚未推送到任何远程时会警告（仓库本地丢失或被清理后将无法重建，请先推送），但不阻止确认；
  - 没有配置远程时不提示。

> [!WARNING]
> 强制删除需勾选授权关闭相关会话，会永久丢弃目录中的全部内容（包括 `.env` 和未提交修改）。分支会保留。

添加的仓库必须可信：Git 会按仓库配置执行 hooks 和 filters。
