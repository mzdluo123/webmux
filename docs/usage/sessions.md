# 会话与工作台

工作台模式用来管理多个终端和 agent 会话：首页按仓库和工作树列出所有会话，点「新建会话」选好位置与启动方式即可进入终端。

最快路径：

1. 点左上角切到**工作台模式**。
2. 点右上角「新建会话」，确认“位置”和“运行”（如 Claude Code、Codex、Shell），点「创建并进入」。
3. 关闭标签页或锁屏不会结束会话；回到首页点会话行即可继续。

只想把任务交给 agent、不关心终端时，用 [聊天模式](chat.md)。

## 侧栏

首页、快速开始页和会话页左侧共用同一个侧栏。左上角的两个按钮在**聊天模式**与**工作台模式**之间切换，当前浏览器记住上次的模式：

- **聊天模式**：侧栏列出聊天记录，主区域是快速开始页 `/new`，见 [聊天模式](chat.md)。
- **工作台模式**：侧栏是「仓库 → 工作树 → 会话」导航树，主区域是会话总览。仓库行的「⋯」菜单提供新建工作树、主页显示、管理工作树与仓库详情；工作树行悬停时（手机上始终）显示删除按钮，打开删除对话框，也可在其中选「仅从主页隐藏」。

侧栏只是两种导航方式：打开任何会话都不会改变当前模式；在会话页切换模式只更换侧栏。

- **侧栏底部**：连接状态与主机名、「添加仓库」按钮（收起为窄栏时同样可用）、端口转发、设置和主题切换。
- **侧栏宽度**：桌面端拖动侧栏右边缘调整（256–480px，未保存时默认 288px，保存在当前浏览器），也可收起成窄栏。窄栏只保留展开按钮和当前模式的主要操作，模式切换需要先展开侧栏；手机上从页面顶栏左侧的按钮打开抽屉。
- **侧栏会话行**：行尾彩色圆点表示状态（绿色工作中、琥珀等待、灰色空闲、空心已结束），与计数一起贴着行尾右对齐：
  - 电脑上鼠标移到行上时“⋯”按钮出现在圆点的位置，手机上按钮常驻在圆点右侧。
  - 点击它打开会话操作菜单，可修改标题、关闭或停止并归档。
  - 已归档聊天可恢复，或选择“删除记录”只删除记录；关联的 linked worktree 可删除时还可选择“删除记录和工作树”，在删除工作树的确认流程成功后一并删除该记录。

## 会话列表

工作台首页按「仓库 → 工作树 → 会话」分组。点会话行在当前标签页进入该会话；中键或 Ctrl/⌘ 点击在新标签页打开，便于同时观察多个会话。

### 范围、搜索与筛选

- 侧栏导航树可切换单个仓库、全部仓库或「直接会话」；点工作树只显示该工作树下的会话。
- 搜索与状态筛选只作用于当前范围。
- 首次在多仓库下进入时优先选有会话的仓库，之后记住当前浏览器的明确选择；已移除的仓库回退到全部。

### 快速切换会话

在工作台、新聊天、终端或设置中，点击“快速切换会话”放大镜。也可以按 `⌘+K`（macOS）或 `Ctrl+Alt+K`（Windows 和 Linux）。

按会话名、启动目录、仓库名或分支名搜索所有仓库及直接会话。点击结果，或用方向键选择后按 Enter。如果会话已在当前分屏中，会直接切换到对应窗格。Esc 关闭面板并恢复焦点。

### 排列与分组

- 仓库按登记顺序排列，可折叠；工作树按路径排列；组内会话按创建时间倒序排列。
- 后台输出和状态更新不会重新排序或挤动其他会话。
- 未关联已登记仓库的会话显示在「直接会话」中；工作树已失效的会话保留在「已不可用工作区」。

### 主页显示哪些工作树

每个仓库只在首页显示“已添加到主页”的工作树：

- 默认只有主工作区；通过页面新建的 worktree 自动添加。
- 侧栏仓库行「⋯」菜单的「主页显示…」打开列表，可搜索并勾选或取消任一工作树。这只改变主页展示，不启动会话。
- 工作树菜单中的「从主页移除」只是不再显示，不会删除工作树。
- 有会话的工作树始终显示，未添加的标注「未添加到主页」。
- 这项选择保存在服务端，并在设备间同步。

### 仓库详情

- 侧栏仓库行「⋯」菜单的「仓库详情…」显示：仓库路径（可复制）、工作树比例、会话计数、Git 读取时间，以及“从列表移除仓库…”。
- 选中仓库后，首页工具栏的「⋯」菜单与侧栏共用这些仓库操作，并增加「仓库设置…」；选中某个工作树时，菜单下半部分是该工作树的「工作树详情…」「添加到主页 / 从主页移除」「删除 worktree」。
- 工作树的路径、分支、状态与会话计数在「工作树详情」对话框中查看；其中的「计算容量」按需遍历目录并显示占用空间与条目数，遍历超限时标注“未统计完整”。
- 异常状态与错误始终可见。

### 预览与紧凑列表

- 默认以输出预览显示终端输出或聊天端最新消息。
- 顶部可切换为紧凑列表：只显示标题、状态、最近活跃时间、连接设备数与混合会话所在端。
- 显式选择的显示方式记在当前浏览器；预览行数仍使用启动配置或全局设置，见 [预览设置](#预览设置)。

### 会话标题

标题按以下顺序取值：

1. 手动设置的标题：会话卡片菜单的“修改标题”，留空保存恢复自动标题；
2. 创建时填写的名称；
3. 终端视图启动且带用户指令（首条 prompt）时，取该指令的文本：去掉控制字符，空白折叠为一个空格，最多 80 个字符，超出以“…”结尾；不含初始化指令，普通 Shell 命令同样适用；
4. 程序设置的标题：终端通过 OSC 0/2，聊天端通过 ACP `session_info_update`；
5. 工作目录名。

聊天端从首条消息取临时标题，agent 上报标题后被替换。第 3 项的名称与第 2 项一样写入会话名称：手动修改后再留空保存，回到工作目录名而不是首条指令。omp 的聊天端不会自动生成标题，可用“修改标题”命名。

### Shell 报告目录（可选）

启用可选 shell 集成后，会话行还会显示「Shell 报告目录」，即程序通过 OSC 7 报告的当前目录：

- 它只是导航线索，不改变会话按启动目录或仓库工作树的归属。
- 远端主机报告的目录标注「远端」，不会用于本机文件定位。
- 会话菜单可复制该目录（没有报告时复制启动目录）。配置片段见 [Shell 目录报告](shell-directory.md)。

### 刷新与加载

- 列表通过 WebSocket 实时更新。
- Git 状态在打开页面、切回前台、重连、手动刷新和操作完成后重新读取。
- 首页立即显示上次的会话列表与设置并在后台刷新，慢速网络下不必等待加载。
- 宽屏顶栏的返回按钮回到当前模式的主页。

## 会话状态

| 状态       | 含义                                                                  |
| ---------- | --------------------------------------------------------------------- |
| 运行中     | 最近 2 秒内有输出，或已无输出但没有提示符、终端读取或关注信号         |
| 可能在等你 | 末行像提示符 / 确认问题，或进程在等待终端输入；`sleep` 等计时休眠不算 |
| 空闲       | 超过 `idle_after_seconds` 无输出，且没有上述等待特征                  |
| 已退出     | 进程已结束，显示退出码（信号退出记为 `128 + signal`）                 |

- 上表是没有任何程序信号时的启发式。程序报告了自己的状态时以报告为准，判定顺序见 [提醒如何影响会话状态](attention.md#提醒如何影响会话状态)。
- 状态只用于展示，不触发任何自动动作。

### 需要你介入的提醒

agent 提问、请求授权或完成一轮时，会话显示具体提醒并保持“等待”：

- **需要回答**、**等待授权**、**出错停止**：醒目的红色徽章；
- **本轮完成**、**有通知**、**响铃提醒**：琥珀色。

omp、Codex CLI（0.164.0+）与 Claude Code（2.1.295+）无需配置即可自动报告状态。信号来源（`OSC 7501`、Warp 结构化事件、桌面通知与响铃）、优先级、清除规则与旧版本 hook 配置见 **[需要你介入的提醒](attention.md)**。

### 浏览器标签页的运行指示

- 当前终端会话或首页任一会话处于运行中（`running`）时，标签页标题增加 `▶` 前缀并循环播放本地生成的 favicon 动画。
- 等待、空闲和已退出恢复静态图标与基础标题；`waiting` 不显示执行中动画。
- 该判定是启发式的，长时间无输出的命令可能在 `idle_after_seconds` 后停止动画。
- 指示不读取或输出终端正文，也不产生逐帧网络请求。
- 系统启用“减少动态效果”时图标保持静态运行帧，标题仍保留标记。

## 新建会话

在工作台首页点右上角「新建会话」。对话框围绕**位置**和**运行**两个选择展开：

1. 确认“位置”：在哪个目录或工作树里运行；
2. 确认“运行”：用哪个启动配置或命令；
3. 可选：填写**用户指令**（创建后自动发送的第一条消息）；
4. 点「创建并进入」。

底部一句汇总（如“将在 webmux · 主工作区 · main 运行 Claude Code”）说明将要发生什么；默认值齐全时打开后可以直接创建。会话名称收在“高级：会话名称”里，留空则取首条用户指令，没有指令则跟随终端标题。

### 1. 选择位置

默认位置按以下优先级确定（对话框里改选位置不会改变首页当前选中的仓库）：

1. 上下文入口：工作树旁的「新建会话」预选该树，终端分屏预填源会话的目录。
2. 首页当前选中的仓库：其可用主工作区，否则该仓库其他可用工作树；都不可用时保留该仓库并要求选择。
3. 最近目录，最后是服务默认目录。

“位置”列表按侧栏当前选中的范围收窄：

| 侧栏选中                                    | 列表内容                                                              |
| ------------------------------------------- | --------------------------------------------------------------------- |
| 某个仓库                                    | 该仓库的所有工作树和“新建工作树…”；不列最近目录、其他仓库与直接目录   |
| 某个工作树（或点了工作树行的「新建会话」）  | 该工作树，以及“从当前工作树分支新建…”（起始分支默认是该工作树的分支） |
| “全部仓库”“直接会话”，或从分屏 / 会话页打开 | 完整列表，见下                                                        |

完整列表包含：

- **直接目录**：选中后出现工作目录输入框与「浏览」。
  - 支持路径补全：↑↓ 选择，Enter / Tab 进入，Alt+↑ 返回上级；
  - 目录不存在时可确认创建。
- **工作树**：在已登记仓库的某个工作树中启动。条目显示分支与路径，不可用或 bare 工作树显示但不可选。
- **新建工作树…**：每个仓库分组末尾都有此项。选中后在位置行下方填写分支，先创建 Git worktree，再启动会话。
  起始提交与存放目录收在“高级：起始提交与存放目录”里，规则见 [仓库与 worktree](worktrees.md#选择起点)。

### 2. 选择运行方式与起始端

“运行”列表包含保存的启动配置和末尾的“自定义命令…”，可搜索、可用键盘选择，Esc 只关闭列表。

- **启动配置**：每项显示图标、名称与命令，以及环境变量数量（不显示值）；长命令可通过完整提示查看。配置保存在服务端，换浏览器或设备后仍可选用。
- **自定义命令…**：选中后出现命令输入框，填写一次性命令，不会写入服务端。
  - 没有保存配置或配置存储不可用时也可使用；
  - 在两者之间切换时保留已选配置与已输入命令，只提交当前选择；
  - 命令为空或引号未闭合时不能创建会话。
- **起始端（混合模式配置）**：选中勾选了混合模式的启动配置时，下方以单选卡片选择**“从终端开始”**或**“从聊天开始”**。
  默认终端，浏览器按每个 Agent 分别记住你上次选择的起始端。

成功创建后，当前浏览器记住最近一次启动方案（启动配置及每个 Agent 的混合起始端，或自定义命令），下次打开直接填入：

- 创建失败不会覆盖它；
- 记住的配置已被删除时显示“选择启动方式”，不会改用其他配置。

### 3. 用户指令与初始化指令（可选）

对话框下方可以填写**用户指令**，在会话创建后自动发出：

- **从聊天开始**：作为聊天的第一条消息发送。
- **从终端开始或自定义命令**：
  - 支持命令行初始提示的混合模式 agent（Claude Code、Codex、OpenCode、omp、Antigravity CLI）通过首次启动参数直接传入；
  - 未迁移的 agent 与自定义命令等程序启动输出并安静约 0.7 秒后（最长等 15 秒）输入到终端并回车；程序开启括号粘贴时多行文本按粘贴发送。

所选位置属于已登记仓库（或分屏保持源会话工作区）且该仓库设置了初始化指令时，上方显示“使用初始化指令”复选框。从聊天开始时默认勾选；从终端开始或使用自定义命令时默认不勾选，因为初始化指令通常是给 agent 的自然语言。
勾选后，展开的仓库初始化指令放在你的用户指令前面一起发送。指令的写法见 [仓库初始化指令](chat.md#仓库初始化指令)。

## 启动配置

启动配置是保存在服务端的一条完整命令（argv + 环境变量），在新建会话和快速开始时选用。在设置页「启动配置」分区新建；点一行编辑，行尾的「⋯」菜单可编辑或删除。

### 预置配置

新安装首次启动会预置 Shell、十一款 CLI agent 和 omp 启动配置，都可以编辑或删除，没有不可修改的内置预设。完整列表见 [CLI agent 接入](../cli-agents.md)。

| 预置配置                                                                      | 默认行为                                                                       |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| Claude Code、Codex CLI、Antigravity CLI、Open Code、Qoder、QoderCN、Kimi、omp | 带自动批准工具调用的参数（Codex 参数同时关闭其沙箱）；需要逐次批准时删掉该参数 |
| Cursor、Copilot、Qwen、CodeBuddy                                              | 使用各 CLI 默认的授权行为                                                      |

- Open Code、omp、Codex CLI、Claude Code、Antigravity CLI、Qoder、QoderCN 与 Kimi 的预置配置默认开启[混合模式](../hybrid-sessions.md)。
- 默认预设只在 `launch-configs.json` 不存在时写入；已有安装的文件不会被改写，删除的预设不会自动重新出现。
- 需要时可在「新建启动配置」旁的「添加系统预设」菜单中补回单个或全部缺失的预设；同名配置已存在时不会覆盖。
- WebMux 不会自动安装 agent。

### 命令怎么执行

命令按 argv 直接执行，**不经 shell 展开**；引号、空参数与参数边界会保留。

- 需要管道、变量等 shell 语法时，显式写成 `bash -lc 'npm run dev | tee dev.log'`。
- 需要加载 `~/.bashrc` 或 `~/.zshrc` 时，勾选“加载 shell 启动文件”（见下）。

### 编辑选项

- **图标**：自动匹配、通用终端、十一款 CLI 品牌图标或 Pi / omp。
- **“输出预览”**：单独设置行数与跳过末尾行数；不设置时跟随服务端全局预览。
- **“完成与介入提醒”**：默认跟随服务端全局提醒配置；取消“跟随全局默认”后可按预设单独配置：
  - **提醒范围**：“全部提醒”、“仅需介入”（只保留提问、授权与出错，抑制完成、通知与响铃）或“关闭”（关闭全部自动提醒，显式 `webmux notify` 仍有效）；
  - **信号来源**：独立开关状态协议（`OSC 7501`）、Agent 事件（Warp 协议）、桌面通知（`OSC 9 / 777`）与终端响铃（`BEL`），按 `OSC 7501 > Agent 事件 > 桌面通知 > 终端响铃` 优先级生效，关闭高优先级项可自动回退到下一层；
  - **防误报过滤**：设置最短回合耗时（0–300 秒）与完成确认延迟（0–60 秒），过滤短暂回合与子任务抢跑提醒。详见 [按启动配置调整提醒与防误报](attention.md#按启动配置调整提醒与防误报)。
- **“加载 shell 启动文件”**：可选 Bash（`~/.bashrc`）或 Zsh（`~/.zshrc`），保存为 `/usr/bin/env bash -ic 'exec -- "$@"' webmux …` 或 `zsh -ic 'exec -- "$@"' webmux …` 的完整 argv。
  - 命令与参数原样传给 `exec`，不展开 `$HOME`、管道或命令替换；
  - 再次编辑保持勾选与所选 shell，不重复包裹；
  - 新建配置按服务端 `$SHELL` 预选，其他 shell 回退 Bash。
- **混合模式**：勾选后创建混合会话，可在聊天视图与终端之间切换，归档后从首页所属工作树的“已归档”中恢复，见 [混合会话](../hybrid-sessions.md)。
  - 聊天输入框支持上传、拖放或粘贴附件：单文件上限 10 MiB，单条消息最多 8 个、合计 20 MiB；
  - Agent 支持时原生发送，否则按服务器路径降级并提示。

启动配置存储不可用时，设置页显示原因与文件路径，仍可填写临时命令启动。

## 设置与偏好

### 设置分区导航

- 桌面在左侧显示分区导航，手机在顶部显示吸顶的横向导航（可左右滑动）。
- 分区：“外观与阅读”“快捷指令”“启动配置”“草稿与暂存”“网络”“公网访问”“Tailscale”“安装应用”“通知推送”“输出预览”。点击滚动定位，当前分区随滚动高亮。
- 导航支持键盘、地址片段直达与浏览器前进后退，不卸载表单，不丢失未保存输入。

### 预览设置

在设置页“输出预览”调整首页会话卡片的预览：

| 选项           | 范围 | 默认 |
| -------------- | ---- | ---- |
| 显示行数       | 1–50 | 10   |
| 跳过末尾的行数 | 0–50 | 1    |

- 设置保存到服务端并同步到已连接设备；保存失败不会覆盖最后确认值。
- 这些全局值用于临时命令和未单独配置预览的启动配置。
- 启动配置可单独覆盖：编辑配置时取消“跟随全局默认”，填写适合该 agent 底栏高度的值。例如 OpenCode 的底栏比 Claude 高，可为其配置跳过更多行。
- 首页卡片按创建时使用的启动配置读取当前预览值；修改配置后回到首页生效，配置被删除时回退全局设置。
- 卡片始终为生效的预览行数保留高度，暂无输出时也不收起。
- 预览只是展示设置，不影响会话进程。

### 跨设备偏好

| 保存在服务端、跨设备同步                                                                                               | 只留在当前设备                                                                                                                         |
| ---------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 主题、输出预览、代码行号、Diff 换行、快捷指令（含系统预设“恢复会话”“新会话”“WebMux 工具”）、主页工作树、强制底部工具栏 | 终端字号（8–20px，默认粗指针 13、细指针 14）、Token、草稿和暂存正文、最近目录、上次启动选择、临时命令、终端尺寸锁定、Web Push 设备身份 |

- 服务端偏好在设置页“外观与阅读”与终端快捷入口中修改，已连接设备无需刷新即可更新。
- 恢复默认使用 null；删除全部快捷指令保存空列表，不重新补默认项。
- 旧版本 localStorage 偏好不自动上传，新版以服务端为准。
- 浏览器仅缓存最后确认的快照，用于首屏和服务不可用时显示；缓存不是待上传队列。
- 设置冲突时重读后按本次字段或 ID 操作重试一次；再次失败保留编辑输入并提示。
- 存储损坏、锁冲突时可在设置页查看错误路径并重新读取；修复原文件后需要重启服务。终端与其他独立功能继续可用。
