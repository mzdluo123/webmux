# Spec Delta

## MODIFIED Requirements

### Requirement: 窄屏顶栏只常驻高频操作

视口宽度小于 640 CSS px 时，终端顶栏 SHALL 只常驻以下控件：

- 打开侧栏：SHALL 始终常驻，取代原来的“返回会话列表”。主屏幕 Web App 没有浏览器后退按钮，侧栏抽屉（见 `app-shell`）提供模式切换、会话总览和其他会话，覆盖原返回按钮的用途。
- 会话标题：SHALL 占用常驻控件之外的全部剩余宽度，超长时省略。
- 状态点（及异常连接文字）。
- 快捷指令入口（按 `terminal-quick-commands` 规定仅在底部工具栏隐藏时出现）。
- 草稿模式开关、终端/代码切换和终端菜单。

全屏（按“全屏入口按平台能力提供”的规则）、上传文件和滚动到最新位置 SHALL 作为终端菜单中的菜单项提供，保持原有的禁用条件、可访问名称和行为（窄屏代码视图下滚动到最新位置仍切回终端）。

视口宽度至少 640 CSS px 时，顶栏 SHALL 保持现有按钮集合与顺序；返回按钮回到当前模式的主页（工作台为 `/`，聊天为 `/new`）。

#### Scenario: 窄屏标题可辨识

- **WHEN** 在 320 px 和 393 px 宽视口打开名称为 `demo-agent` 的会话，终端视图和代码视图各查看一次
- **THEN** 顶栏单行、无横向溢出，393 px 下完整显示 `demo-agent`，320 px 下显示省略后的标题；顶栏不出现全屏、上传和滚动到最新位置按钮

#### Scenario: 从菜单上传文件

- **WHEN** 窄屏用户打开终端菜单并选择“上传文件”
- **THEN** 打开与原上传按钮相同的文件选择流程，上传进度、草稿模式下的路径写入和失败提示保持原有行为

#### Scenario: 宽屏布局不变

- **WHEN** 在 1440 px 桌面浏览器中打开终端
- **THEN** 顶栏仍直接显示全屏、上传文件、滚动到最新位置、快捷指令入口、草稿和代码切换按钮

#### Scenario: iOS 主屏幕 Web App 窄屏

- **WHEN** 在 iOS 27 iPhone 上从主屏幕 Web App 打开会话
- **THEN** 顶栏位于状态栏安全区下方，打开侧栏按钮可用，标题可辨识；终端菜单中的上传文件可打开系统文件选择器

#### Scenario: 窄屏从会话回到总览

- **WHEN** 窄屏用户在会话页点击顶栏左侧的打开侧栏按钮，再选择工作台模式下的“全部仓库”
- **THEN** 抽屉关闭，当前标签页进入工作台首页
