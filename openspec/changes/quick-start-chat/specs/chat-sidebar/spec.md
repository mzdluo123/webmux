# Spec Delta

## Purpose

聊天侧栏在快速开始页和会话聊天页左侧常驻，按最近活动列出运行中和已归档的聊天会话，让用户不回首页就能在聊天之间切换、恢复已结束的聊天或新开一个聊天。

## ADDED Requirements

### Requirement: 侧栏出现位置

快速开始页和混合会话的会话页（聊天视图与终端视图）SHALL 在左侧显示聊天侧栏；首页、设置页和纯终端会话页不显示。

- 侧栏顶部 SHALL 有“新聊天”（指向快速开始页）和“会话总览”（指向首页）。
- 桌面端侧栏可以收起和展开，收起状态保存在本设备。
- 在侧栏中切换会话、新开聊天都 SHALL 在当前标签页内完成，不重新加载页面，也不打开新标签页。

#### Scenario: 从会话切到另一个聊天
- **WHEN** 用户在会话 A 的聊天页点击侧栏中的会话 B
- **THEN** 当前标签页进入会话 B，侧栏保持原来的滚动位置，并把 B 标为当前项

#### Scenario: 收起侧栏
- **WHEN** 用户在桌面端收起侧栏后刷新页面
- **THEN** 侧栏保持收起，展开按钮仍可见并有可访问名称和提示

#### Scenario: 新聊天
- **WHEN** 用户在任一会话页点击侧栏顶部的“新聊天”
- **THEN** 当前标签页进入快速开始页，侧栏中没有当前项

### Requirement: 列表内容与排序

侧栏 SHALL 列出全部聊天会话：运行中的混合会话，加上服务端保存的已归档混合会话记录。纯终端会话不列出。列表平铺，不分组，按最近活动时间从新到旧排列：运行中会话取最近活动时间，归档记录取最后更新时间。列表随会话事件实时更新，不需要刷新。

#### Scenario: 新建的会话出现在顶部
- **WHEN** 快速开始成功创建会话
- **THEN** 该会话出现在侧栏顶部，并被标为当前项

#### Scenario: 不列出终端会话
- **WHEN** 服务中同时运行着一个 Shell 会话和一个混合会话
- **THEN** 侧栏只列出混合会话

#### Scenario: 会话结束
- **WHEN** 一个运行中的聊天会话结束，服务端为它保存了归档记录
- **THEN** 侧栏中只保留这一条，状态显示为已结束，不出现重复项

### Requirement: 行内容

每行 SHALL 显示会话标题、agent 图标和运行状态。状态分为工作中、等待（等待用户回答问题或批准权限）、空闲、已结束四种，用颜色加文字或可访问名称表达，不只依赖颜色。标题过长时截断，并保留完整标题的提示。当前会话行 SHALL 标记 `aria-current`。

#### Scenario: agent 请求权限
- **WHEN** 某个后台聊天中的 agent 发出权限请求
- **THEN** 侧栏中该行状态变为等待，并用注意色和“等待”文字表示

#### Scenario: 长标题
- **WHEN** 会话标题长于侧栏宽度
- **THEN** 行内标题截断、不换行，悬停或读屏能获得完整标题

### Requirement: 打开已归档的聊天

点击已归档的记录 SHALL 走现有的恢复流程：可以恢复时进入恢复后的会话聊天页；不能恢复时（例如 worktree 已删除或 agent 不可用）说明原因，不新建会话。

#### Scenario: 恢复归档聊天
- **WHEN** 用户点击一条 worktree 仍然存在的已归档聊天
- **THEN** 系统恢复该 agent 会话，当前标签页进入其聊天页，侧栏中该行变为运行中状态

#### Scenario: 无法恢复
- **WHEN** 用户点击一条所在 worktree 已被删除的归档聊天
- **THEN** 页面说明无法恢复及原因，不创建会话，侧栏条目保留

### Requirement: 手机端抽屉

在小于 `sm` 的视口上，侧栏 SHALL 默认隐藏，通过页面左上角的按钮以抽屉形式打开。选中会话或点击“新聊天”后抽屉自动关闭。抽屉打开时焦点进入抽屉，关闭后回到打开按钮。

#### Scenario: 手机切换会话
- **WHEN** 用户在 390×844 视口点击左上角按钮，再点击另一条聊天
- **THEN** 抽屉关闭，当前标签页进入该聊天，终端或聊天区占满宽度

### Requirement: 侧栏不改变混合会话的行为

侧栏 SHALL 只是现有会话页旁边的导航。会话页里的聊天视图、终端视图、切换、代码面板、通知和关闭等行为 SHALL 与没有侧栏时一致。侧栏 SHALL 只读取现有会话列表和混合会话记录，不新增会话类型或会话字段。无论会话是从快速开始、新建会话弹窗还是 CLI 创建的，只要是混合会话就出现在侧栏里。

#### Scenario: 从新建会话弹窗创建的混合会话
- **WHEN** 用户通过新建会话弹窗以“从终端开始”创建了一个混合会话
- **THEN** 该会话同样出现在侧栏中，状态按其所在端的运行状态显示

#### Scenario: 在侧栏旁切换端
- **WHEN** 用户在带侧栏的会话页把会话从聊天切到终端
- **THEN** 切换过程与结果和没有侧栏时一致，侧栏中该行保留，状态随会话更新
