# Proposal

## Why

聊天、代码侧栏和分屏终端各用一套空间管理方式。用户想同时看 Agent 回复、文件改动和测试输出，也想临时放大其中一项，再回到原来的位置。

## What Changes

- 会话内采用分组停靠：聊天、文件树、阅读器和各终端都能独立排列或合并成标签。
- 标题栏支持最小化、最大化和原位还原；空间操作保持会话和输入归属。
- 手机沿用底部选择器，按实例切换单个面板；宽屏布局独立保留。
- Git 的历史、提交、分支和贮藏模式分别支持自由停靠；切换模式恢复各自布局，沿用原有 Git 操作和手机步进流程。

## Capabilities

### New Capabilities

- `session-panel-workbench`：会话页及 Git 模式内的面板布局、可见性、恢复和响应式切换。

### Modified Capabilities

无已归档能力增量。与在途 `mobile-panel-picker-sheet` 的接续见设计：保留入口与抽屉交互，替换固定目的地契约。

## Impact

涉及会话页、Git 工作台、代码工作区、终端分屏与浏览器本地布局。保留现有会话协议、混合视图切换权限、终端生命周期和 Git 写操作确认。
