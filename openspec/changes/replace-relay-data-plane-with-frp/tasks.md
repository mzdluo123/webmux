- [ ] 3.1 在节点镜像固定 frps，代理仅使用 loopback 和受控端口池；在现有 HTTPS 入口按精确域名/路径区分浏览器、管理连接与 frp。核对 IPv4/IPv6 实际监听和发布映射，外部不能直达插件、端口池或 dashboard；TURN 原端口仍正常。
- [ ] 3.2 在现有节点代理实现 Login/NewProxy/NewWorkConn/Ping 私有钩子，核对时效、活动分配、角色与登录关联。使用两台各自合法的宿主验证跨账号、重复登录、旧修订、错误端口及插件不可用均拒绝，原合法连接不被替换。
- [ ] 3.3 在宿主发行、安装、更新和回滚流程交付受签名清单约束的 frpc；分别验证 Linux/macOS amd64、arm64 与 WSL 中的 Linux 制品。替换制品、缺件或版本不兼容只关闭该 Relay 模式，本机 PTY 仍可用。
- [ ] 3.4 实现宿主受限运行目录、JWT 原子更新、固定目标 WSS 桥、独立管理连接与子进程监督。验收普通续期不中断终端，关闭、禁用落盘失败、异常退出和启动竞争后不会遗留可用路由、重复进程或凭据泄漏。
- [ ] 3.5 实现分配专属的网关/宿主 mTLS 与 readiness；成功探针必须经实际注册端口获得专用入口 204。验证端口重用、错 EKU/SAN、公钥或旧代际均不会发送业务数据；公网不能访问该探针。
- [ ] 3.6 协议适配私有 `internal/dataplane` 的网关拨号；保留 Host、Origin、CSRF、反代头清理、流式收发、取消和配额。验证超过 128 个等待者或 15 秒返回 429，离线 503，回源失败 502；工作连接失败不重放上传或终端输入。
