# Spec Delta

## MODIFIED Requirements

### Requirement: 主机身份与固定公共主机名

Relay SHALL 为主机生成至少 128 位随机熵的 DNS 安全标识，持久绑定账号数字 ID、固定 Origin 与主机公钥；标识独立于 Token 和私钥。重启保留地址，删除后重新配对产生新地址。
管理连接 SHALL 以单次随机质询验证宿主 Ed25519 签名，绑定协议、管理角色、受众、主机及绑定/连接代际。只有当前已认证管理连接可申请专属短期业务授权；业务角色不能冒充管理连接。

#### Scenario: 错误私钥不能劫持主机名

- **WHEN** 其他宿主声称拥有已知公共标识但不能证明持有配对私钥
- **THEN** 认证失败，原绑定、活动管理连接与路由保持不变。

#### Scenario: 重放已捕获的认证响应

- **WHEN** 另一次挑战、服务或角色收到先前响应
- **THEN** 拒绝认证及派发业务凭据，不替换当前授权。

#### Scenario: 删除后重新配对

- **WHEN** 所有者删除绑定并再次配对
- **THEN** 新地址不同；旧标识和旧传输凭据不能启动新路由。

### Requirement: 单活动连接器与撤销

每个绑定 SHALL 同时只有一个经权威分配的活动管理代际和一种活动业务传输。新合法管理代际原子取代旧代际；业务重连或无效注册不能取代管理连接。
管理断开、换钥、关闭或解绑 SHALL 移除路由、取消活动代理及工作连接并拒绝迟到注册，保持 PTY；管理通道每 10 秒心跳、失联判定最长 30 秒。仅业务断开 SHALL 停止业务回源，允许有效管理通道继续处理撤销。

#### Scenario: 同一主机的重复连接

- **WHEN** 同一绑定成功完成新管理认证，旧业务进程仍在线
- **THEN** 仅新代际可发布路由；两个版本、重复登录和延迟健康通知均不能同时取得入口。

#### Scenario: 主机断开

- **WHEN** 管理连接关闭或失去保活监督
- **THEN** 撤销该代际，后续请求返回 503；其他宿主不受影响。

### Requirement: 完整 HTTP 与 WebSocket 反向代理

公网网关 SHALL 精确匹配公共 Host，保留 Host、Origin、状态码和非逐跳头，清除伪造身份/转发头。回源仅使用当前授权绑定和代际且经双向认证的 WebMux 专用入口，不接受请求指定的目标。
REST、二进制下载、流式响应、multipart 上传、语音、终端/聊天 WebSocket 及 `/forward/*` SHALL 保持完整性、背压和取消语义。回源失败返回 502、已知宿主离线返回 503、准入饱和返回 429；不得整包缓存或重放已发送请求。

#### Scenario: 通过 Relay 使用终端

- **WHEN** 浏览器登录并打开 `/ws/s/{id}`
- **THEN** 帧、关闭码、回放和实时输入输出保持；未获宿主授权者得到拒绝，即使节点隧道仍可达。

#### Scenario: 大文件上传期间执行其他请求

- **WHEN** 大文件上传的同时发起会话列表、终端或聊天连接
- **THEN** 使用独立工作连接与交互预留；取消上传及时释放预算，其他请求继续取得进展。

#### Scenario: 未知或离线主机名

- **WHEN** 请求指向未登记 Host 或没有活动回源的已登记 Host
- **THEN** 分别返回 404 或 503，均不得转入其他主机。

### Requirement: 流控、配额与故障隔离

Relay SHALL 集中限制配对速率、每主机和账号活动连接数、带宽、缓冲、认证及排队；达到活动上限执行有界等待，队满或到期返回 429 和 Retry-After。管理心跳与撤销不计入普通流配额。
连接、认证、工作分配、无进展写入及关闭 SHALL 有界；长时间空闲但健康的终端不受普通 HTTP 短读超时影响。慢端不得占尽其他宿主资源。

#### Scenario: 慢客户端不耗尽服务内存

- **WHEN** 一个浏览器停止接收且达到有界缓冲和无进展期限
- **THEN** 关闭该工作连接并释放名额，管理及其他主机继续工作。

#### Scenario: 超过单主机 stream 配额

- **WHEN** 请求超过活动额度，随后队满或等待到期
- **THEN** 返回 429 和 Retry-After；既有终端不被驱逐，准入等待者最多每账号 128 个、最长 15 秒。

### Requirement: 固定多 TCP WSS 传输与性能证据

新分配 SHALL 使用独立管理 WSS 与受管反向业务隧道，单个在途代理请求独占工作连接；交互/批量是网关准入类别，不要求预建 2/4 个数据槽位。账号带宽共用，64 个普通流额度中 bulk 至多 56，控制消息始终独立。公网基线不依赖 UDP。
服务端 SHALL 配置并核实 BBR 与实际接口队列；客户端只记录可观测的 TCP 算法。重连不自动重放非幂等请求，终端按 generation/offset 续接；所有活动流、队列、套接字及缓冲有界。

#### Scenario: bulk 失败保持交互可用

- **WHEN** 批量工作连接中断，但管理连接和其他交互工作连接健康
- **THEN** 关闭受影响传输，释放其名额；终端与撤销继续工作，不迁移或隐式重放上传。

#### Scenario: control 断开立即撤权

- **WHEN** 管理连接断开或租约超时，业务通道仍通
- **THEN** 公共来源和全部派生业务会话失效，已打开的 WebSocket、转发和直连关闭；不等业务凭据到期。

#### Scenario: 性能与内存有证据

- **WHEN** 以同线路旧版作对照，分别注入随机/突发丢包、限速、并发下载、慢端与连接中断
- **THEN** 记录样本量、真实回显 p50/p95/p99、超时数、有效吞吐、连接数、FD、RSS 和恢复耗时，标明覆盖边界。

#### Scenario: 按键响应与输出完整性共同验收

- **WHEN** 同一 PTY 持续输出时输入，或同时执行另一终端重输出与下载
- **THEN** 以真实 PTY 回显计时，计入失败样本；同时验证输出完整、Ctrl-C 和断线续接，不以单次探针替代。

## ADDED Requirements

### Requirement: 按代际签发与验证业务授权

控制面 SHALL 仅给当前通过持钥证明的宿主签发限时业务凭据，绑定发行方、节点受众、宿主、绑定及管理代际、唯一授权标识、允许注册项和到期时间。续期重新核验权威状态。业务凭据不授予节点管理、GitHub、TURN 或浏览器会话权限。
节点 SHALL 校验实际登录及后续心跳和工作连接的凭据与已认证会话归属。签名、期限、当前代际、用途或受众不符即拒绝；进程自报名称、metas、客户端指定 run ID 和全局共享 Token 均不能证明归属。

#### Scenario: 两个合法宿主之间保持隔离

- **WHEN** A 与 B 各自持有有效授权，A 请求注册 B 的代理、复用 B 的会话标识或给 B 的工作连接提供 A 的凭据
- **THEN** 拒绝该操作，不更改 B 的路由、配额和已有连接。

#### Scenario: 已消费或过期的登录授权

- **WHEN** 新进程重用已用于创建登录会话的票据或被撤销代际的票据
- **THEN** 拒绝建立或替换会话；恢复须经过有效管理授权取得新登录许可。验证服务失效时拒绝新授权。

### Requirement: 私有回源端口与会话隔离

节点 SHALL 仅授权为当前代际保留的一项私有 TCP 回源；拒绝通配域、额外端口、路由重写和其他代理类型。注册通过后，必须由网关完成代际专属双向 TLS 与实际宿主响应验证才发布路由。端口重用不能继承原授权。
公网访问仍 SHALL 由宿主按原有登录、Origin、CSRF 与会话权限判断；授权服务对隧道关闭与浏览器注销分别确认。

#### Scenario: 注销并保留其他会话

- **WHEN** 用户注销一个浏览器后台会话，隧道保持健康
- **THEN** 对应 Cookie、已打开终端、转发和派生 P2P 失效；其他合法浏览器与宿主 PTY 保留。

#### Scenario: 私有端口尚可达但目标已更换

- **WHEN** 网关连到已回收端口或未持有当前代际回源身份的服务
- **THEN** 双向验证失败；不向该服务传送 HTTP 头、Cookie、终端内容或业务请求。
