# Spec Delta

## ADDED Requirements

### Requirement: 仅全新主机配对

WebMux SHALL 在本机生成并保存独立的 Ed25519 中继密钥对。配对 SHALL 使用 v2 接口、有效机器 ID 和新公钥，返回官方验证地址、一次性用户码和有效期供用户完成 GitHub 授权；WebMux 登录 Token MUST NOT 出现在请求中。
私钥、轮询句柄和 GitHub 凭据 MUST NOT 出现在状态响应、诊断、日志或浏览器持久化中。配对失败或过期 SHALL 允许重试，不改写 WebMux 登录 Token。
已有绑定 SHALL 要求先通过已授权删除，再进行全新配对；客户端 MUST NOT 提供保留域名恢复、rebind 或同机自动换钥。明确拒绝 SHALL 清理待配对密钥及 pending 状态；不确定网络、上游或限流失败 SHALL 保留有效句柄、密钥和取消入口。

#### Scenario: 从设置页完成配对

- **WHEN** 用户开始全新配对并在官方页面完成 GitHub 授权
- **THEN** 本机保存新绑定，显示新公共地址且不自动启用公网访问，不保存 GitHub 访问凭据

#### Scenario: 配对接口不包含登录 Token

- **WHEN** 宿主创建或轮询配对请求
- **THEN** 请求只包含机器 ID、中继公钥或配对材料，不包含 WebMux 登录 Token

#### Scenario: 账号已有绑定

- **WHEN** 用户配对时账号仍有绑定
- **THEN** 显示先删除旧绑定的冲突说明，不提交隐式恢复或换钥请求

#### Scenario: 轮询明确拒绝后重试

- **WHEN** 配对轮询明确拒绝当前尝试
- **THEN** 清除待配对状态及密钥，可立即重新发起全新配对

#### Scenario: 轮询遇到不确定网络失败

- **WHEN** 当前配对因网络、上游故障或限流失败
- **THEN** 保留句柄和密钥及取消入口，不自动以新密钥替换

#### Scenario: 取消返回已终止

- **WHEN** 取消当前配对返回句柄已终止的明确错误
- **THEN** 清理当前尝试并刷新状态，允许重新配对；不因不确定取消失败丢弃句柄

### Requirement: 新版绑定持久化与安全降级

Relay 的启用意图、控制端点、主机标识、完整公共 HTTPS Origin 和私钥 SHALL 使用登记的 v3 状态文件，保持目录 0700、文件 0600、原子写入及独立锁；MUST NOT 保存公开控制 controltrust。
宿主 MUST NOT 读取或迁移旧 v1/v2 绑定；升级 SHALL 先备份并清除旧绑定状态，保留独立机器 ID，重新配对，默认关闭公网访问。未知或损坏状态 SHALL 保留并报告不可用，不回退 TOML 暴露服务。
数据面分配 SHALL 每次经已认证控制面重新取得，不作为手工第二端点或持久信任来源。关闭落盘失败仍 SHALL 立即停止公网授权并返回未持久化错误。TOML 仅提供现有引导配置，不保存绑定、私钥、旧别名或公开控制 pin；正常 v3 重启 SHALL 按持久启用意图连接。

#### Scenario: 损坏设置阻止自动暴露

- **WHEN** 状态文件损坏且 TOML 配置为启用
- **THEN** 本机服务正常运行，Relay 关闭并显示存储错误

#### Scenario: 关闭时存储写失败

- **WHEN** 用户关闭 Relay 而状态无法写入
- **THEN** 当前公网授权及连接立即撤销，并提示修复存储后重新保存

#### Scenario: 旧版绑定不再迁移

- **WHEN** 新宿主遇到 v1/v2 绑定状态
- **THEN** 拒绝恢复旧密钥及启用意图；完成备份清理后以未配对、关闭状态启动，独立机器 ID 不变

## REMOVED Requirements

### Requirement: 本地密钥与账号配对

**Reason**: 移除恢复、原地换钥及保留旧地址的配对生命周期。
**Migration**: 删除已有绑定，使用 v2 全新配对取得新地址。

### Requirement: 受控持久化与安全降级

**Reason**: 移除旧版绑定状态的兼容及自动迁移。
**Migration**: 备份后清理旧绑定状态，保留独立机器 ID，再重新配对。

## MODIFIED Requirements

### Requirement: 设置操作与删除绑定

WebMux SHALL 在公网访问设置中提供开始配对、启停、刷新状态和删除绑定操作，并显示期望开关、运行状态、地址及失败原因；MUST NOT 提供恢复或重新绑定入口。
删除绑定 SHALL 停止自己的连接与派生访问；官方 Relay 确认记录已删除后，SHALL 清除本地绑定、私钥和待配对密钥，即使旧访问关闭未确认。无法确认删除时 SHALL 保留本地身份以便重试。界面 SHALL 区分记录删除和旧 P2P 访问关闭，不伪造关闭证明，并明确告知新配对取得新地址。
设置操作 SHALL 保留现有 API 认证和 Origin 校验；界面在桌面与手机布局可用，并在当前操作会断开正在使用的公网页面时给出确认提示。

#### Scenario: 成功删除绑定

- **WHEN** 用户确认删除且官方 Relay 确认记录已删除
- **THEN** 自己的连接停止、公共来源撤权、本地私钥与绑定被清除；旧访问未确认关闭时明确警告

#### Scenario: 删除时官方服务不可达

- **WHEN** 用户删除绑定但 Relay 控制面无法确认记录已删除
- **THEN** 本地连接保持关闭，绑定信息保留用于重试，不声称删除或旧访问关闭
