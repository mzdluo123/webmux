# Spec Delta

## MODIFIED Requirements

### Requirement: 账号配对与单主机绑定

Relay SHALL 支持以 GitHub 设备授权完成主机配对。未配对的宿主 SHALL 能提交新生成的公钥及可选机器 ID 并取得一次性用户码、验证地址和轮询句柄；只有用户在有效期内完成授权后，Relay 才建立账号与公钥绑定。
每个账号 SHALL 同时最多绑定一台主机。同账号且机器 ID 非空相同 SHALL 允许自动恢复；其他已有活动绑定 SHALL 要求显式重新绑定。恢复 SHALL 保留原公共主机名、递增绑定代际、撤销旧公钥并断开旧连接器及派生授权。
用户码和轮询句柄 SHALL 单次使用且有有效期。Relay SHALL 对配对创建与轮询实施速率限制，且 MUST NOT 要求或接受 WebMux 登录 Token。
MVP SHALL 使用 GitHub 账号允许列表实施邀请制。未获邀请的账号 SHALL 在授权完成后收到明确拒绝，不占用主机绑定或公共主机名。机器 ID MUST NOT 单独授权覆盖或跨账号修改绑定。

#### Scenario: 完成首次配对

- **WHEN** 宿主提交新公钥，用户在有效期内通过 GitHub 完成授权
- **THEN** Relay 将账号的数字身份与公钥及机器 ID 绑定，并返回固定公共 HTTPS 地址

#### Scenario: 过期或重复使用的配对码

- **WHEN** 配对码已过期、已使用或轮询句柄无效
- **THEN** Relay 拒绝建立或修改绑定，并要求重新发起配对

#### Scenario: 未邀请账号完成授权

- **WHEN** 不在允许列表中的 GitHub 账号完成设备授权
- **THEN** Relay 返回邀请制拒绝原因，不创建绑定或分配公共主机名

#### Scenario: 显式重新绑定丢失的密钥

- **WHEN** 已绑定账号确认用新公钥替换旧公钥
- **THEN** 公共主机名保持不变，旧私钥不能再建立连接，旧活动连接被关闭

#### Scenario: 同账号同机器自动恢复

- **WHEN** 已授权且获邀请的同一数字账号提交与旧绑定相同的非空机器 ID 及新公钥
- **THEN** 即使没有显式替换标记也恢复旧宿主并撤销旧代际，只有完成撤权后才报告恢复完成

#### Scenario: 旧记录或不同机器不能静默替换

- **WHEN** 旧记录机器 ID 为空或与请求不同，且用户没有明确确认替换
- **THEN** Relay 返回冲突并保持绑定、域名、公钥和代际不变

#### Scenario: 并发恢复不能丢失更新

- **WHEN** 同一账号两个请求重叠恢复同一旧代际
- **THEN** 最多一个事务替换该旧代际，另一项返回冲突，不覆盖已提交的新身份

## ADDED Requirements

### Requirement: 所有者删除机器

Relay SHALL 允许已登录且获邀请的所有者在账号控制台确认删除自己的机器，并校验同源 Origin、CSRF 与绑定代际。
删除 SHALL 撤销旧公钥、连接和派生授权并移出列表；未完成撤权 MUST NOT 报告完成。
系统 SHALL 保留必要撤权记录与固定域名，允许删除后重新完成账号授权的普通配对复用该域名。
其他账号、缺少授权或过时代际 MUST NOT 删除当前绑定。
主机撤权 SHALL 保留账号控制台身份用于查询进度；退出控制台或撤销邀请仍 SHALL 执行账号级撤权。

#### Scenario: 所有者确认删除

- **WHEN** 所有者确认删除匹配当前代际的机器且旧访问已经撤销
- **THEN** 机器从列表移除，旧身份和授权失效，后续普通配对可通过重新授权复用域名

#### Scenario: 删除响应尚待撤权

- **WHEN** 服务端已撤销绑定但尚未确认旧访问关闭
- **THEN** 返回待完成状态，客户端不得显示删除成功，并保持同一机器与代际的后续检查

#### Scenario: 迟到删除不能撤销新绑定

- **WHEN** 旧代际删除请求在新的配对完成后到达
- **THEN** 请求被拒绝，新公钥、机器身份和绑定代际保持不变
