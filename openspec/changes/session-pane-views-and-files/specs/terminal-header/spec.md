# Spec Delta

## MODIFIED Requirements

### Requirement: 连接状态只在异常时显示文字

会话窗格标题栏 SHALL 在该会话标题旁显示状态点。正常连接只显示状态点；重连、退出或会话不存在时显示对应单行文字。状态点的可访问名称和提示 SHALL 包含会话状态与连接状态。该规则适用于桌面与手机。

#### Scenario: 连接正常

- **WHEN** 用户在桌面或手机打开已连接的运行中会话
- **THEN** 标题栏不重复显示「已连接」文字，状态点可访问名称包含会话状态和「已连接」

#### Scenario: 连接中断后恢复

- **WHEN** A 断开并重连，B 始终已连接
- **THEN** 仅 A 标题旁显示单行「重连中」；恢复后该文字消失

### Requirement: 窄屏顶栏只常驻高频操作

工作区顶栏 SHALL 容纳导航、文件、布局、当前可见会话的操作和设备显示入口。手机标题行保留会话名称与状态；点击标题可查看详情和修改名称。两行各自保持单行，高频按钮使用 44px 触控区域；文件树或阅读器占据当前面板时省略会话操作。

#### Scenario: 窄屏标题可辨识

- **WHEN** 在 320 px 和 393 px 视口打开名为 demo-agent 的会话
- **THEN** 页面无横向溢出，可获取完整会话名；空间不足时标题可截断。顶栏依次显示侧栏、切换会话、文件、面板、会话操作与显示，标题及状态只在下方显示

#### Scenario: 从菜单上传文件

- **WHEN** 用户从窄屏顶栏的终端菜单选择「上传文件」
- **THEN** 沿用该会话原上传禁用条件、文件选择、进度、草稿路径写入及失败提示

#### Scenario: 宽屏布局移除滚动到最新位置按钮

- **WHEN** 桌面同时显示多个会话窗格
- **THEN** 返回入口按模式回到工作台或聊天主页；文件、布局与浏览器全屏在工作区层，上传、快捷指令和草稿作用于所在窗格。滚动到最新仍由终端内容区提供

#### Scenario: iOS 主屏幕 Web App 窄屏

- **WHEN** 从 iOS 主屏幕打开会话并使用工具栏
- **THEN** 控件位于安全区内；上传仍可从会话菜单打开，全屏入口遵循现有平台能力规则

#### Scenario: 窄屏从会话回到总览

- **WHEN** 手机用户打开工作区顶栏的侧栏入口并选择工作台的「全部仓库」
- **THEN** 抽屉关闭，当前浏览器标签页进入工作台首页

### Requirement: 全屏入口按平台能力提供

支持 Fullscreen API 的浏览器 SHALL 从工作区标题栏切换整个工作区全屏；手机使用工作区菜单。API 不可用时，普通标签页保留入口并提示可添加到主屏幕；独立运行的主屏幕应用不显示该入口。窗格放大在两种情况下均沿用停靠布局能力。

#### Scenario: iPhone Safari 标签页

- **WHEN** 手机浏览器不支持页面全屏，用户从工作区菜单选择「全屏」
- **THEN** 显示添加到主屏幕的提示，窗格布局不变

#### Scenario: iPhone 主屏幕 Web App

- **WHEN** 独立运行且不支持 Fullscreen API 的应用显示工作区菜单
- **THEN** 工作区没有浏览器全屏项；窗格操作仍然可用

#### Scenario: iPad 支持全屏

- **WHEN** 支持 Fullscreen API 的平板用户从工作区选择「全屏」
- **THEN** 整个会话工作区进入浏览器全屏，可以从同一层退出

## ADDED Requirements

### Requirement: 会话视图切换随窗格移动

每个混合会话窗格 SHALL 在激活并可见时向工作区顶栏提供视图切换入口，声明当前视图和不可用原因；手机使用「⋯」菜单首组。纯终端窗格省略切换器。停靠组的标签代表不同窗格，不再以同一会话的聊天和终端填充两个标签。

#### Scenario: 窗格重排后按键盘切换

- **WHEN** 用户将 A 移到 B 右侧，激活 A 后用键盘操作视图切换
- **THEN** 控件的可访问上下文标明 A 和当前视图；只有 A 响应，文件树及阅读器均不显示会话切换器

### Requirement: 标题栏按操作对象分配控件

桌面与手机的会话操作 SHALL 由活动窗格提供，呈现在工作区顶栏。桌面窗格标题行显示名称或堆叠标签、状态、窗格菜单和收起按钮；手机会话标题行仅保留会话身份。

每个操作 SHALL 归属下表中的层级，宽屏与手机保持相同对象。窄屏可将按钮折入同层菜单；入口名称、提示、禁用条件及执行结果 SHALL 与目标一致。窗格动作从打开菜单、选择文件到异步完成均绑定发起窗格。

#### Scenario: 桌面与手机逐项核对操作归属

- **WHEN** 用户在包含两个会话的工作区查看标题栏和菜单
- **THEN** 每个控件及对应的紧凑菜单项均按下表归属：

| 现有控件或操作         | 唯一归属                                                             | 行为                                                                                     |
| ---------------------- | -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 聊天 / 终端            | 活动会话菜单栏（手机：顶栏「⋯」）                                    | 切换本会话的显示方式；能力不足时按视图切换契约呈现                                       |
| 上传（上箭头）         | 活动终端菜单                                                         | 文件送到发起窗格的会话，进度及草稿路径仍属于它                                           |
| 快捷指令（闪电）       | 既有软键栏；隐藏软键栏时使用顶栏（手机：终端菜单）                   | 指令发给本终端或插入本会话草稿；同一时刻只有一个入口                                     |
| 草稿（笔记图标）       | 活动终端菜单或该窗格紧凑输入区                                       | 开关、草稿内容与暂存笔记属于本会话                                                       |
| 打开面板（分栏图标）   | 工作区标题栏「布局」                                                 | 管理窗格、分屏、新建、加入和恢复；「文件」是同层独立入口                                 |
| 全屏（四角图标）       | 工作区标题栏                                                         | 切换整个浏览器工作区全屏，保留全部可见窗格与比例                                         |
| ⋯ 内的会话命令         | 工作区顶栏的活动会话菜单                                             | 查找、暂存笔记、清屏、重新同步、锁定当前终端尺寸、交接及停止、归档、移除，仅作用于该会话 |
| 放大或还原、收起、移动 | 桌面窗格标题栏及顶栏「窗格」；手机顶栏「打开面板」抽屉提供收起与恢复 | 收起保留会话进程；桌面可选收起边缘，点击边栏标签还原布局                                 |
| 终端字号               | 顶栏终端菜单「显示」                                                 | 调整本机终端字体，聊天视图不提供该项                                                     |
| ⋯ 内的设备显示偏好     | 工作区菜单「显示」                                                   | 键盘弹出时保持尺寸、显示底部工具栏沿用设备偏好作用域                                     |
| ⋯ 内的页面导航和全屏   | 工作区标题栏或其紧凑菜单                                             | 返回或打开侧栏、切换会话、浏览器全屏均不借用终端菜单                                     |

#### Scenario: 发起命令后焦点移到另一窗格

- **WHEN** A 与 B 并排，在 A 发起上传后焦点移到 B，或打开 A 的快捷指令、草稿或清屏菜单
- **THEN** 命令与结果仍归 A；B 没有收到文件、输入或清屏操作。若 A 已移除，取消该动作，不转投 B

#### Scenario: 全屏与放大分别还原

- **WHEN** A、B 与文档并排，在工作区进入浏览器全屏，然后放大 B 并还原 B
- **THEN** 全屏时三者仍可见；放大时仅 B 占据内容区；还原后三者恢复原比例，浏览器仍为全屏

#### Scenario: 窄屏菜单保留作用域

- **WHEN** 用户在手机分别打开工作区「显示」和会话 A 的顶栏「⋯」
- **THEN** 终端字号、上传、查找和停止 A 在会话菜单，全屏在「显示」。切到 B 后会话菜单按 B 的能力和连接状态显示；文件树和阅读器可见时不提供会话菜单
