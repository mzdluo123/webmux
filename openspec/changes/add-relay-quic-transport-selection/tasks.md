# Tasks

## 1. 隔离环境与协议契约

- [ ] 1.1 固定两端 frp 版本，在隔离宿主和节点完成原生 QUIC 工作连接、双向认证回源 204、应用 HTTP 和 WebSocket；保存脱敏结果并确认业务数据经过 UDP。
- [ ] 1.2 为控制协议加入能力协商和限时候选分配；双版本组合测试确认旧宿主或旧节点只使用 WSS，未知端点无法触发拨号。
- [ ] 1.3 在两端验证节点证书、宿主分配、连接代际与共享配额；覆盖证书不符、跨宿主、过期和撤销，证明均无法访问回源。

## 2. 节点与宿主切换

- [ ] 2.1 节点实现独立候选注册和仅探针可达的目标；令旧路径健康而候选失败，验证不会借用旧 204 提交。
- [ ] 2.2 实现限时操作与条件提交；测试并发、响应丢失、取消及撤销竞态，验证至多一个生效协议且临时资源全部释放。
- [ ] 2.3 宿主保存已确认的选择并实现重启恢复；测试 UDP 不可达时无虚假生效协议，本机可切回 WSS。
- [ ] 2.4 更新私有节点部署说明与 US-A09 验收；在隔离节点演练能力发布、停止签发、切回 WSS 和关闭 UDP。

## 3. 设置与诊断

- [ ] 3.1 扩展设置 API、状态 DTO、CLI JSON 与前端校验；用同一次试连核对设备间生效协议、节点、耗时、阶段、时间和回源观测。
- [ ] 3.2 在官方中转设置实现双语「测试并应用」，覆盖未支持、进行中、成功及失败保留状态；验证键盘、手机触控和桌面截图。
- [ ] 3.3 更新 US-A10 与客户端使用说明；按文档从远端试连失败恢复到原链路，并验证本机恢复入口。

## 4. 端到端对照

- [ ] 4.1 固定宿主、节点及浏览器路径，在正常、限速丢包和 UDP 不通三档交替测试；分别记录冷启动资源成功率、真实 PTY 按键 p95/p99、超时数和重连时间。
- [ ] 4.2 使用隔离 PTY 在两方向切换期间发送可计数输入；验证进程存活、能重新附着、输入不重复，并在撤权后确认两协议均停止访问。
