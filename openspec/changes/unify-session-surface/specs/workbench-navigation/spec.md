## MODIFIED Requirements

### Requirement: 从工作台打开会话

在工作台模式下打开会话时（点击树中的会话行，或主区域的会话卡片），系统 SHALL 按会话当前所在的端决定模式：

- 混合会话处于聊天端（`view` 为 `chat` 且 `transition` 为 `null`）：自动切到聊天模式，侧栏换成聊天历史并选中该会话，主区域显示它的聊天视图；记住的模式随之改为聊天。
- 其他会话（普通终端会话、处于终端端的混合会话、切换中的混合会话）：保持工作台模式，主区域显示该会话的终端，侧栏仍是导航树并选中该会话。

模式只在打开时决定一次。打开后会话在两端之间切换，SHALL NOT 再自动改变模式。通过地址直接打开或刷新会话页时，使用记住的模式，不自动切换。

#### Scenario: 打开运行中的终端会话
- **WHEN** 用户在工作台树中点击 webmux → brisk-otter 下运行中的 `pnpm dev`
- **THEN** 侧栏仍是导航树并选中这一行，右侧主区域显示该会话的终端

#### Scenario: 打开处于聊天端的混合会话
- **WHEN** 用户在工作台树中点击正在聊天端工作的 Claude Code 会话
- **THEN** 整个界面切到聊天模式：左上角“聊天”按钮为选中态，侧栏显示聊天历史并选中该会话，主区域显示它的聊天视图

#### Scenario: 打开处于终端端的混合会话
- **WHEN** 用户在工作台树中点击一个已切到终端的混合会话
- **THEN** 保持工作台模式，主区域显示它的终端；会话页仍可按现有规则切回聊天，切回后模式不变
