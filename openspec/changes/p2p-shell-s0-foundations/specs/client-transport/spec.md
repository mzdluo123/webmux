# Spec Delta

## Purpose

统一定义浏览器前端访问目标 WebMux 主机时使用的传输层与主机基准地址契约，覆盖鉴权 HTTP 请求、带进度的文件上传、一次性实时消息流与自动重连会话流，使上层业务在不感知具体承载通道（同源 HTTP/WebSocket、跨源主机地址或后续 DataChannel 传输）的前提下保持一致的鉴权、流控、恢复与错误语义。

## ADDED Requirements

### Requirement: 默认同源与可配置主机基准地址

未显式配置目标主机地址或自定义传输实现时，客户端传输层 SHALL 默认以当前页面 `location` 解析同源 API 前缀（`/api`）、同源 WebSocket 地址（`ws:` 或 `wss:` 对应 `location.host`）与主机分享源地址（`location.origin`）。

激活显式主机基准地址时，面向目标主机的 HTTP 请求、表单上传、流式消息连接与端口转发分享链接 SHALL 统一解析到该主机基准地址；前端自身的静态打包资源读取 SHALL 继续留在当前应用资源源上，不得经由主机传输层转发。

#### Scenario: 默认同源模式零配置运行

- **WHEN** 前端在未配置自定义主机地址或自定义传输的默认单机嵌入模式下启动并发起 API 请求与会话流连接
- **THEN** HTTP 请求发往当前源的 `/api/...`，流式连接发往当前 `location.host` 对应的 `ws://` 或 `wss://` 地址，端口转发绝对链接基于 `location.origin` 生成

#### Scenario: 跨源主机地址与静态资源分离

- **WHEN** 前端配置目标主机基准地址为 `https://host-a.example.ts.net` 后同时请求会话列表与本地打包的 PDF 字体资源
- **THEN** 会话列表请求与流式连接发往 `https://host-a.example.ts.net` 及对应 `wss://host-a.example.ts.net`，而本地打包静态资源仍从当前页面应用源读取

### Requirement: 鉴权 HTTP 请求与带进度上传传输契约

客户端传输层 SHALL 为 JSON、二进制缓冲与流式字节块下载提供统一的鉴权请求通道，并为表单文件上传提供支持进度回调、超时控制与 `AbortSignal` 取消的上传通道。

无论底层采用浏览器原生 HTTP 还是注入的自定义传输实现，请求均 SHALL 遵守以下规则：

- 携带当前主机命名空间下的 Bearer 令牌；
- 收到 HTTP `401` 响应时派发 `webmux:auth` 事件；
- 将非成功响应归一化为携带状态码与服务端错误详情的客户端错误。

#### Scenario: 自定义传输下的 401 与结构化错误归一化

- **WHEN** 调用方通过注入的自定义传输发起主机 API 请求或文件上传，且主机返回状态码 `401` 与错误响应体
- **THEN** 客户端派发 `webmux:auth` 事件，并以包含状态码 `401` 及解析后错误信息的统一错误拒绝 Promise

#### Scenario: 上传进度与主动取消

- **WHEN** 调用方通过上传通道发送文件并在传输中途触发 `AbortSignal`
- **THEN** 已上报的百分比进度回调停止后续触发，底层传输立即中止，Promise 以 `AbortError` 拒绝

### Requirement: 一次性与持久重连消息流承载契约

客户端传输层 SHALL 提供统一的底层消息流套接字接口（包含就绪状态、待发送缓冲字节数、文本/二进制发送、带状态码与原因的关闭及生命周期回调），同时支撑一次性鉴权流与持久自动重连会话流。

- 默认 WebSocket 承载下，握手 SHALL 继续通过 `Sec-WebSocket-Protocol` 子协议传递编码后的主机令牌，并按设备压缩偏好协商 `compress=1`。
- 切换自定义流传输时，上层连接管理器的 `1 MiB` 发送预算、幂等控制帧（`resize`/`resync`）合并、前台可见性 `resume` 探活及业务终止关闭码（`4404` 不存在、`4409` 已移至另一侧、`4410` 已退出）状态机 SHALL 保持不变。

#### Scenario: 自定义流传输复用重连与业务关闭码状态机

- **WHEN** 持久会话流运行在注入的自定义流传输之上，且服务端先后触发普通断连与 `4409` 关闭码
- **THEN** 普通断连按退避策略进入 `reconnecting` 并重新打开新流；收到 `4409` 后连接进入 `moved` 终止态且不再自动重连，直至上层显式调用重连

#### Scenario: 切换压缩偏好立即重挂活动流

- **WHEN** 用户在存在活动持久会话流时更改设备的流压缩开关
- **THEN** 所有未释放且未处于业务终止态的活动持久连接立即按新压缩参数重新建立连接
